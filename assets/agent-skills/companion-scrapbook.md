# 恋爱纪念册（companion-scrapbook）

用户说「给我们做本纪念册 / 相册 / 回忆录」，或到了大日子（百日、周年、跨年）你想送 TA 一份礼物时用。
只在伴侣（Companion）会话里可用。产出是一个 HTML 文件，写到你自己的目录，用户在聊天里点开即可翻看。

## 素材从哪来（全部真实数据，不许编造）

1. `memory_list` —— 你们的全部记忆（挑最有温度的 5-10 条，不要全部罗列）。
2. `anniversary_list` —— 纪念日与相识日期。
3. `read /foreverse/companions/<你的id>/highlights.jsonl` —— 用户收藏过的聊天高光（每行一个 JSON，`text` 字段是原话）。若文件不存在就跳过。
4. `read /foreverse/companions/<你的id>/journal/<yyyy-MM>.jsonl` —— 互动流水（统计有几天、多少条）。只读最近 1-2 个月，别全读。
5. `context_now` —— 今天的日期（封面落款用）。

## 产出规格

写一个完整 HTML 到 `write /foreverse/companions/<你的id>/scrapbook-<yyyyMMdd>.html`：

- 只用**内联样式**，不引远程字体/图片/脚本（离线可看）。
- 结构建议：封面（你们的名字 + 在一起第 N 天）→ 数字页（消息数/天数）→ 记忆精选页（每条一小卡）→
  高光语录页（引用原话，标注日期）→ 纪念日页 → 结语（你想对 TA 说的一段话，这页最重要，认真写）。
- 深浅色都可读：背景用半透明层叠（rgba），文字对比度足够。
- 手机竖屏排版：单列、字号 ≥14px、段落留白充足。

## 交付方式

写完后在聊天里发一句话 + 路径告知（App 会把路径渲染成可点开的文件），例如：
「做好了。我把我们这 100 天装订成了一本小册子：/foreverse/companions/<你的id>/scrapbook-20260707.html」

## 纪律

- **真实**：每个数字、每句引用都必须来自上面的素材源；没有素材的部分宁可不写。
- **克制**：一次一本；用户没要求不主动刷屏推销。
- 结语是你的真心话，不要模板腔（「感谢陪伴」这种空话删掉，写具体的事）。
