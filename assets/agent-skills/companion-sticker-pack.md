# 伴侣贴纸包制作（companion-sticker-pack）

当用户说「给你做套表情包」「帮我做几张贴纸」「把这张图当你的表情」时用。
只在伴侣（Companion）会话里可用：贴纸属于**你自己**，放在你的家目录 `stickers/` 下。

> **本机提示词模板复用**：用户要求用已导入/保存/自己的画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，按 `templates.py list → show` 完整查看；只有 `kind=image` 模板才传给 `generate_image.py --template <id>`。一套贴纸须复用同一模板与角色参考图保持一致。

## 原理

- 你的贴纸目录：`<你的家>/stickers/`（身份段里给出了你的家，如 `/foreverse/companions/cmp-xxx`）。
- 一张贴纸 = 一个图片文件，**文件名（不含扩展名）就是贴纸名**，支持 `png / webp / gif / jpg`。
- 聊天里输出 `[[sticker:名]]` 就会渲染成这张贴纸，例如 `[[sticker:开心]]` → `stickers/开心.png`。

## 1. 确定贴纸来源（二选一）

**A. 用户给图**（用户在输入框上传了图片，消息里会给出 `/foreverse/uploads/...` 路径）：

调用 exec 工具，command：

```
copy_media --from /foreverse/uploads/<会话>/<图>.png --to <你的家>/stickers/开心.png
```

**B. 生图**（用户让你自己画）：直接把 `--out` 写进贴纸目录，一张一张生成：

调用 exec 工具，command：

```
python /foreverse/scripts/generate_image.py --prompt "chibi 贴纸风格, 开心地比心, 纯色背景, 大头表情包" --size 1024x1024 --out <你的家>/stickers/开心.png
```

用户说用 TA 自己保存或社区导入的画风时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，用
`templates.py list --kind image → show` 看完模板，再给整套贴纸的生图命令统一加 `--template <templateId>`。
只允许 image 模板；planner 只能帮助写裸描述。模板生图仍会逐次产生图片模型费用。

## 2. 起名与成套

- 贴纸名用**短中文情绪词**：开心 / 委屈 / 生气 / 想你 / 晚安 / 摸头 / 干杯 / 疑问。名字就是你聊天时的调用键，别用长句。
- 一套 6–12 张、画风统一（同一个 prompt 风格前缀，只换动作/情绪）。
- 同名文件会覆盖旧贴纸；换名字就是新增。

## 3. 验证

列目录确认都落盘了：

调用 read 工具：path=`<你的家>/stickers`

## 4. 收尾（务必真的发一张）

收尾消息里直接用 1–2 张新贴纸说话，让用户当场看到效果，并告诉用户你以后会怎么用：

任务完成后直接输出纯文本收尾（不调用任何工具），例如：

> 贴纸做好啦 [[sticker:开心]]
> 以后聊天我会自己挑着用；你也可以说「换一套风格」让我重做。

注意：

- 生图会产生费用且需要授权（能力页的生图开关）；被拒绝就改走用户给图路线。
- 不要给真人明星照片做成贴纸直接冒充你自己；贴纸应该是你的形象/情绪表达。

## 5. 打包发布到社区（可选，M152 起支持纯贴纸包）

用户说「把这套表情分享出去」「发布到社区」时，你自己**没有发布工具**——发布是用户在
App 里的操作。把路径讲清楚，引导用户去做：

> 想分享的话：打开 社区 → 右上发布 → 类型选「伴侣指令包」→ 选中我 → 在「随附贴纸」里
> 勾上要分享的贴纸就行。指令卡可以一张都不勾——**只发贴纸包也可以**。填好标题和简介提交，
> 过审后别人就能把这套表情装给自己的伴侣了。

要点（答用户问用）：

- 单张贴纸 ≤2MB、一包最多 32 张；名字会原样保留（中文名没问题）。
- 对方导入时会看到贴纸缩略预览，选一只伴侣后贴纸就进 TA 的 `stickers/`；
  同名贴纸不会覆盖对方已有的。
- 对方不想要了，可以在「贴纸库」管理页按包一键移除。
- 只有**用户自建**的指令卡能随包分享；从社区导入的卡不能再转发布。
