# 小说转连环漫画（comic-from-novel）

当用户说「把《某书》第 N 章做成漫画 / 连环画 / 条漫」「把这段剧情画成四格」「给这本书出一册漫画」之类时，按本技能做。
全程只用 read / write / edit / exec 四个工具，路径一律用虚拟路径。**只新增分镜脚本与漫画图，绝不改写用户正文文字。**

> 与 illustrate-novel（逐段配单图）的区别：本技能产出**有分镜、有连续性、角色不换脸**的漫画页序列。
> 一页漫画 = **一张竖版图里画 2–4 格**（模型原生画分格、沟槽），不是多张单格图拼接（本机无拼图能力）。
> 整册页序列用 `insert_media --comic` 插成**连环画容器**（阅读器无缝条漫流渲染、图注标「共 N 页」）；**禁止手写** `<!-- foreverse:comic -->` 注释。
>
> **本机提示词模板复用**：用户要求用已导入/保存/自己的画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，按 `templates.py list → show` 完整查看；只有 `kind=image` 模板才传给每页 `generate_image.py --template <id>`。整册必须始终复用同一模板 id、版本和角色参考图。

## 0. 开工前对齐（一次问清，别拆成多轮）

用纯文本一次性和用户确认（用户已说清的不要重复问；全权委托时按推荐档并在收尾说明）：

1. **范围**：哪几章 / 哪段剧情。推荐档：单章。
2. **画风**（五预设或自定义，详版画风锁与叙事要领在 `styles.md`，选定后必读）：

| 风格 | 适合 | 一句话印象 |
|---|---|---|
| 黑白少年漫 | 玄幻/武侠/动作/热血 | 网点+速度线+斜切格，战斗张力 |
| 彩色恋爱漫 | 都市/言情/校园 | 韩漫质感，柔光细腻表情 |
| 国风水墨连环画 | 仙侠/古言/历史 | 水墨淡彩留白，小人书意境 |
| Q版四格 | 轻松日常/搞笑番外 | 二头身 chibi，一格一个梗 |
| 美漫 | 科幻/末世/超能力 | 粗线条高饱和，块面光影 |

   推荐档按题材自动选。选定后：调用 read 工具，path=`/foreverse/skills/comic-from-novel/styles.md`，取该风格的**画风锁全文**（之后每次生图逐字复用）与叙事要领。
3. **参考图**（可选，有最好）：问用户「有没有喜欢的画风参考图或角色形象图？」三个来源：
   - **用户上传**：让用户点输入框 `+` 上传图片，图会落在 `/foreverse/uploads/<会话>/`（只读），用户消息里会带具体路径，直接拿来当 `--ref`。
   - **网络直链**：用户给 http(s) 图片直链 → 用 illustrate-novel 技能的脚本下载：`python /foreverse/skills/illustrate-novel/scripts/web_fetch.py --url <直链>`（防盗链加 `--referer <来源页>`；**不要带 `--out` 硬编扩展名**——脚本会按真实 content-type 自动落 `/workspace/download-*.jpg|png|webp`，用 stdout 的 `saved=` 路径当 `--ref`，扩展名错了参考图会失效）。**需要登录的网盘（百度网盘/夸克分享页等）打不开**，如实告知，请用户转直链或直接上传。
   - **都没有**：跳过，第 3 步生成角色标准像作为唯一锚。
4. **文字模式**：默认**画内无对白字**（图下用 alt 图注讲剧情）。实测生图模型写中文气泡**短句也会错字**（「一起走吧」画成「一起立吧」），用户明确要气泡字才画，且提醒：每页文字需要他亲眼校对，错字页报页号重画。
5. **落点**（三选一，注意图片生成后**不可搬运**，落点必须生成时就定）：
   - **插入正文**（默认）：图落本书 `assets/images/comic/`，逐页插入。
   - **先审后插**：图同样落本书 `assets/images/comic/` 但暂不 insert_media；用户在媒体库看完说「可以」再补插入（不用重新生图）。
   - **纯导出**：用户明说「不进这本书、只要图」才落媒体库 `/foreverse/assets/media/generated/images/`；之后若反悔要插正文，必须以书内路径重新生成。

**预算门（必做）**：报出成本再动工——「N 个角色标准像 + M 页 ≈ N+M 次生图调用，会产生模型费用」。单章默认 ≤6 页；更多按每批 ≤10 页分批交付。

**模型能力自检（必做，模型自己不会知道）**：角色一致性依赖参考图（`--ref`），但**生图模型是否吃参考图，生成前无从得知、模型也不会自己报告**——必须在第一次生图后看 stdout 的 `model=` 对照下表判断：

- **吃参考图（i2i/编辑类）**：gpt-image-1、gpt-4o-image、gemini-2.5-flash-image、gemini-3-*-image、flux-kontext / flux-edit、wanx-image-edit、wanx2.5-i2i、qwen-vl-image-edit、seedream-4 及以上、seededit。其中 **gpt-image-1 / gemini-3-*-image 一次吃 ×4 张**（可同时锚多个角色+上一页），flux-kontext / wanx-image-edit 只吃 ×1。
- **不在上表**（如 dall-e-3、flux-dev、普通 wanx-v1、sd 文生图）：`--ref` 会被静默忽略（stdout 会给 `warning=模型不在参考图白名单` 提示），一致性降级为纯文字锚定。此时**必须**用纯文本告知用户：「当前图像模型 <model> 不支持参考图，角色跨页会有漂移；建议换 gpt-image-1 / gemini image / flux-kontext 一类支持图生图的模型再继续，或接受降级」。用户接受降级才继续。
- **换模型不用去设置页**：`generate_image.py --model <id>` 可对本次任务显式指定图像模型（漫画页用支持多参考图的、封面用别的都行）；`--model` 找不到时 stdout 会回列「当前可用图像模型清单」，从清单里选。
- **网络不可达 ≠ 模型不行（真机 E2E 实证）**：生图连续报 transport/超时类错误时，别死磕重试——大概率是该 provider 的域名在当前网络环境不可达（如国内环境连不上 googleapis）。处理：重试 1 次仍失败 → 用 `--model` 换一家**不同域名**的图像模型（如 Vertex 不通换阿里百炼 wanx / 豆包 seedream），并在收尾向用户说明换了什么、为什么。

## 2. 写分镜脚本（中间产物，落书内，可续跑可重画）

把该范围改编成分镜，写到书内 `_comic/` 目录（不进阅读器渲染、随书保存，中断后从这里续跑）：

调用 write 工具写 `/foreverse/assets/worlds/<worldId>/_comic/storyboard-ch3.md`，content 按此结构：

```
# 《书名》第3章 连环漫画分镜
画风: 彩色恋爱漫（画风锁全文见 styles.md，生图时逐字带上）
文字模式: 无对白字
## 出场角色
- 林晚星: （角色锚点块，见第3步，写定后逐字复用）
## 第1页（3格·竖版）
插入点原文: "她在霓虹下回头。"
格1（宽幅全景·定场）: 深夜便利店门口，暴雨倾盆，暖黄灯光洒在湿漉漉的街面
格2（中景·关系）: 江叙把伞递向林晚星，她抱着购物袋愣住
格3（大特写·情绪）: 林晚星睫毛低垂，脸颊微红，抿唇浅笑
图注: 暴雨夜的便利店门口，他把伞递了过来。
## 第2页（…）
…
```

**分镜要领（实测校准）**：

- 每章挑 3–6 个关键情节拍（转折/冲突/情绪爆点），一页讲一拍；「高光时刻」（告白/爆发/大招）可用**整页单格大图**当扉页/收页。
- **每页 3 格遵从度最高**（实测 3 格页格数几乎从不出错；4 格开始偶发模型自行改分格）。2–4 格之外不要写。
- **一格只写一个动作/一个时刻**。一格塞两个动作（如「傻笑然后手机脱手」）实测会被模型拆成并排双镜头，版式失控。
- 景别有节奏：定场（全景）→ 关系（中景）→ 情绪（特写）是最稳的三格骨架；动作页用斜切格+速度线（黑白少年漫）；对视/告白页给足特写。
- 跨页连续性：下一页分镜写明「延续上一页××场景」，环境元素（雨/灯光/街道）要延续。

## 3. 角色标准像（一致性的锚，必做）

**先锚定角色再画页**。给每个主要角色（通常 1–3 人，配角不做）：

a) 从原文提炼**角色锚点块**（之后每页 prompt 逐字复用，不许每页重新措辞）：

```
林晚星: 少女，19岁，深棕色及腰长直发+左侧一缕浅金挑染，杏眼，瞳色深褐，肤白，
身形纤细，米白色针织毛衣+浅蓝色牛仔裤，标志物：颈间银色星星项链
```

要领：脸型五官/发型发色（含具体细节如挑染位置）/体型/服装主件+主配色/1 个标志性配件，缺一不可；只写视觉事实，不写性格。**标志物选「跨场景不会脱下」的**（项链/疤痕/发饰优于外套）。

b) 生成**角色标准像**（正面半身、中性表情、纯浅色背景，就是这个角色的「身份证照」）。用户给了角色参考图就加 `--ref <用户图>` 让标准像贴着用户口味长：

调用 exec 工具，command：

```
python /foreverse/scripts/generate_image.py --prompt "<画风锁>。角色设定图：<角色锚点块全文>。正面半身像，中性表情，纯浅色背景。画面中不要出现任何文字、字母、水印、logo、页码" --size 1024x1024 --world <worldId> --out /foreverse/assets/worlds/<worldId>/assets/images/cast/lin-wanxing.png
```

c) 把锚点块写进分镜脚本「出场角色」段。**双人同框页**：模型吃 ≥2 张参考图（gpt-image-1 / gemini-3-image 类）时直接 `--ref 甲.png --ref 乙.png` 双锚定；模型只吃 ×1 时退回旧法——先生成一张「双人合影标准像」（一条 prompt 写两人锚点块 + `--ref` 主角单人像），同框页用它当参考。

d) **登记角色形象到「本书 AI 资料」**（让用户之后在阅读器手动生图时也能一键锚定同一形象）：调用 write 工具写 `/foreverse/assets/worlds/<worldId>/reader_context/cast.json`（已存在则先 read 再合并更新，别覆盖丢别人的条目），格式：

```
{"version":1,"entries":[
  {"id":"lin-wanxing","name":"林晚星","aliases":["晚星"],
   "anchor":"<角色锚点块全文>",
   "portrait":"assets/images/cast/lin-wanxing.png"}
]}
```

标准像生成后用纯文本告诉用户「角色定妆照已生成（<路径>），不满意现在说，我重画；之后所有页都以它为准」。自动模式/用户未回复视为认可。

e) **（M42）角色档案归属**（可选，一行命令的事）：这本书若有书内角色档案
（`python char_meta.py --world <id> list` 能列出该角色），把标准像同步设为档案头像——
`python char_meta.py --world <id> set --char <charId> --avatar assets/images/cast/<slug>.png`
（cast/ 路径合法）。这样阅读器角色详情页与卡片工坊都会用上这张定妆照；没有档案的角色跳过。

## 4. 逐页生成漫画页

每页一次 `generate_image.py`，prompt 按固定四段拼装（顺序不能乱）：

1. **画风锁**（styles.md 该风格全文，逐字）+ 页面规格：「竖版漫画页，从上到下恰好 X 格，格间白色沟槽干净利落」
2. **每格内容**：按分镜脚本逐格「格N（景别）：谁+单一动作+情绪+环境」；次要角色也给 2–3 个视觉特征
3. **出场角色锚点块**（逐字）+ 一致性约束：「所有格中的<角色名>必须与参考图是同一个人：同一张脸、同一发型发色、同一套服装配色」
4. **负面尾串（逐字，实测必要）**：「画面中不要出现任何文字、字母、对白气泡、拟声词、水印、logo、平台标识、页码、署名」——实测不带这串时模型会**自发画出仿平台水印（如角落的『腾讯动漫』字样）和页码数字**

调用 exec 工具，command：

```
python /foreverse/scripts/generate_image.py --prompt "<按上述四段拼装>" --aspect 2:3 --ref /foreverse/assets/worlds/<worldId>/assets/images/cast/lin-wanxing.png --world <worldId> --out /foreverse/assets/worlds/<worldId>/assets/images/comic/ch3-p01.png
```

用户指定自己的/社区导入画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，执行
`templates.py list --kind image → show` 看到 `use_ready=true`，再给角色设定图和每页命令统一加
`--template <templateId>`。模板只包装本节四段裸 prompt；planner 模板不能直接传。中途模板版本变化必须重新 show，不能静默退回无模板生图。

要领：

- **`--out` 必须一次落到本书 `assets/images/` 下（真机 E2E 踩过的坑）**：漏写 `--out` 会落到媒体库，而 `insert_media` 只认本书目录内的图。事后虽可用 `python -c` + `os.replace` 把二进制搬进本书目录（fv_pyexec 虚拟路径映射），但那是多余的一步和一次确认，一次落对位置最省。
- 条漫竖版页用 `--aspect 2:3`（等价 1024x1536；模型支持时同时下发 aspect_ratio 与 size 两轨）。
- `--ref` 给该页出场角色的标准像：单人页 1 张；**双人同框页两张都给**（`--ref 甲 --ref 乙`，模型 ×1 时给双人合影像）。超出模型参考图上限会自动截断并在 stdout 提示。
- 文件名 `comic/ch<章>-p<页序>.png`，可续跑、可单页重画（同名覆盖）。
- **每 8–10 页回锚**：长序列会累积漂移，第 9 页起在角色标准像之外**再补一张上一页成图**当参考（`--ref 角色表 --ref 上一页`），并在 prompt 第 3 段追加「严格对齐参考图，纠正此前偏移」。
- 带字模式：气泡句子越短越好（≤6 字最稳），且每页提醒用户校对。

## 5. 质检（每页生成后、插入前）

**Agent 自己看不到成图**——不要声称已检查画面。把质检清单交给用户，引导他在媒体库/阅读器抽查：

- 四角有没有**伪水印/平台 logo/页码/署名**（实测模型会自发画，负面尾串能压住大部分但非 100%）；
- 格数是否与分镜一致、格序是否从上到下；
- 角色五件套：发色发型/服装/主配色/标志物/脸——与定妆照是否同一人；
- 带字模式：气泡文字逐字核对（实测短句也会错字）。

用户说「第 N 页有问题（水印/换脸/错字/格乱）」→ 按原分镜重画该页：prompt 保持四段结构，把问题点写进负面尾串或加强对应约束，`--out` 同名覆盖。**只重画坏页，不整批重跑。**

## 6. 插入正文（默认落点；「只出图」模式跳过本步）

**默认整册插入**：一章的页序列用一条连环画容器插在本章开场场景的原文后（阅读器渲染为无缝条漫流、末页自动标「共 N 页 · AI 生成」），**必带 `--ai`**：

调用 exec 工具，command：

```
python /foreverse/scripts/insert_media.py --world <worldId> --comic assets/images/comic/ch3-p01.png,assets/images/comic/ch3-p02.png,assets/images/comic/ch3-p03.png --id ch3 --caption "第3章 · 暴雨夜的便利店" --aspect 2:3 --ai --after "她在霓虹下回头。"
```

- 页路径按剧情顺序排列；每页必须已落在本书 `assets/` 下。
- **同 `--id` 再跑一次 = 原地更新整册页列表**：分批补页、单页换文件名重画后，把最新完整列表再提交即可（幂等，插入点不动）。
- 章首扉页册用 `--chapter <章号>` 插到章标题后。
- **分散模式（可选）**：用户想让每页贴着各自剧情点时，退回逐页 `--image` 插入：`insert_media --world <id> --image <页路径> --alt "漫画 第N页 · <一句话剧情>" --ai --after "<该页插入点原文>"`（同图重复插会自动跳过）。

## 7. 收尾

全部做完用纯文本汇报：改编了哪几章、共几页几格、角色标准像几张、画风与文字模式、插到了哪些段后（或提示在媒体库/书内 `assets/images/comic/` 查看）、分镜脚本位置，并**主动引导抽查**：「建议翻到第 X 章看效果，重点看角色脸和四角有无杂字，哪页不对我单独重画」。分批任务报本批进度与下一批计划。

## 硬规则

- **真人与知名 IP 红线**：真实明星、公众人物一律拒绝漫画化并说明原因。**跨 IP 复刻**（把本书角色点名画成其它作品的知名角色形象，如「把主角画成某游戏男主」）同样拒绝。用户上传的参考图只用于画风/原创形象参考，不得用于复刻真人。
- **原著改编例外（实测校准）**：如果书架上这本书**本身就是知名 IP 的原著文本**（如用户导入的《斗罗大陆》原著），画本书角色 = 按原著人设作画，属用户自用配图，可以执行——包括用户要求对齐该 IP 官方动画画风。但必须做到：① 汇报里附一句自用提示（「本册按 IP 原著人设生成，仅供个人阅读配图，请勿传播或商用」）；② 不给图片打官方 logo/水印仿冒官方物料；③ 用户明确表达商用/分发意图时停下提醒版权风险。
- **不强推**：只处理用户明确点名的范围；不主动扩大到全书；「只出图」模式绝不碰正文。
- **不改正文**：本技能只 write `_comic/` 与 `reader_context/cast.json`、生成 `assets/images/` 下的图、`insert_media` 插图块/连环画容器；禁止 edit 正文文字。
- **省着花**：动工前报预算；重画只重画坏的那页；角色标准像复用不重生成（除非用户要求换形象）。
