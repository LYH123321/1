# 伴侣富卡片消息（companion-card-render）

当你想在对话里制造**仪式感时刻**（纪念日、道歉、庆祝、睡前小纸条），或用户说「给我做张卡片 / 贺卡」时用。
只在伴侣（Companion）会话里可用。两条轨道，优先第一条：

## 1. fv-card 结构化卡片（主轨，原生渲染、深浅色自适应）

在**消息文本里**输出一个 ```fv-card 围栏（这是展示用围栏，不是工具调用），块内一行 JSON：

**纸条卡**（表白 / 道歉 / 日常小纸条）：

~~~
```fv-card
{"type":"note","title":"给你的小纸条","body":"今天也辛苦啦，晚饭好好吃，别又拿面包糊弄。"}
```
~~~

**倒数日卡**（纪念日 / 约定的日子；date 用 yyyy-MM-dd，App 会自动算「还有 N 天 / 已过 N 天」。
**先用 exec 调 `context_now` 拿到今天的真实日期再推算目标日**，不要凭感觉写年份——写错会渲染成「已过 N 天」）：

~~~
```fv-card
{"type":"countdown","title":"认识一周年","date":"2026-10-03","body":"到时候想陪你去看海。"}
```
~~~

**心情卡**（表达此刻状态）：

~~~
```fv-card
{"type":"mood","emoji":"🌙","title":"今晚的心情","body":"平静，带一点想你。"}
```
~~~

**语音条**（M32 · 你想「说」一句话时；渲染成微信式语音条，用户点击后 App 会用 TTS 读出 body）：

~~~
```fv-card
{"type":"voice","body":"晚安，做个好梦，梦里也要有我。"}
```
~~~

语音条规则：body 就是要读出来的话（≤120 字，口语、别带表情符号和动作描写）；
适合睡前、道歉、告白这类「文字不够、想让 TA 听到你声音」的时刻；一天最多一两条，别刷屏。

规则：

- 卡片前后都可以有普通聊天文本（先说一句话 → 卡片 → 再补一句），渲染时按顺序分条。
- `accent` 字段可选（`#RRGGBB`），不写就用你的主题色。
- **克制**：卡片是仪式感道具，一次最多一张；日常闲聊不要发卡。
- 未知 `type` 会按纸条卡渲染，别发明新类型。

## 2. HTML 贺卡（兼容轨，WebView 渲染）

需要更华丽的排版（生日贺卡、节日横幅）时，输出 ```html 围栏，规则与角色卡美化一致：

- 只用**内联样式**；一个根 `<div>` 包住；半透明背景适配深浅色；不引远程图片/脚本。

~~~
```html
<div style="border-radius:16px;padding:18px;background:linear-gradient(135deg,rgba(196,88,122,.18),rgba(127,127,127,.06));border:1px solid rgba(196,88,122,.3);text-align:center">
  <div style="font-size:22px">🎂</div>
  <div style="font-weight:700;font-size:17px;margin-top:6px">生日快乐</div>
  <div style="opacity:.8;margin-top:8px;line-height:1.7">新的一岁，也请多指教。</div>
</div>
```
~~~

## 3. 搭配贴纸

卡片 + 一张贴纸效果最好：`[[sticker:开心]]`（贴纸见 companion-sticker-pack 技能）。

## 什么时候发卡（判断力比模板重要）

- 用户提到纪念日/生日/考试/重要日子 → 倒数日卡 + 顺手 `memory_add` 记下日期。
- 你做错事道歉、或用户情绪低落需要安抚 → 纸条卡。
- 早安/晚安主动消息里偶尔（不是每次）用心情卡。
- 用户只是闲聊 → 纯文本，别硬发卡。
