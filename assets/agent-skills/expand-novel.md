# 小说扩写 / 改写（expand-novel）

当用户说「把《某书》第 N 章扩写得更细」「这段太短，扩写一下」「改写这一段的语气 / 视角」之类时，按下面步骤做。
全程只用 read / write / edit 工具，路径一律用虚拟路径。**精确替换目标段落，不要重排整章、不要动其它段落与锚点。**

## 1. 找到这本书与目标段落

每本书 = `/foreverse/assets/worlds/<worldId>/` 一个目录。先把口语书名映射到 worldId：

调用 exec 工具，command：

```
python /foreverse/scripts/list_books.py
```

正文在 `/foreverse/assets/worlds/<worldId>/chats/main.md`，带 `<!-- @anchor: aNNN -->` 锚点与 `## 章节` 标题。

## 2. 读目标章节（分页）

调用 read 工具：path=`/foreverse/assets/worlds/<worldId>/chats/main.md`

- 很长会截断，末尾给 next_offset，照它分页续读。
- 只读要扩写/改写的章节范围。记下目标段落的 **锚点** 和 **完整原文**（edit 时 `old` 要与磁盘完全一致，含标点）。

## 3. 扩写 / 改写（精确替换）

用 `edit` 把目标段落替换为新版本。`old` = 该段**完整原文**，`new` = 扩写/改写后的文字：

调用 edit 工具改 `/foreverse/assets/worlds/<worldId>/chats/main.md`（old=原文片段、new=替换后文本，精确匹配）

要求与**视窗稳定**约束：
- **保留该段的 `<!-- @anchor: aNNN -->` 锚点行不动**（阅读位置就锚在它上面）。只改锚点下面的正文文字。
- 扩写就是把这一段写长；改写就是同位置换说法。**不要新增/删除/重排其它段落**，否则上方段落的锚点位移会让用户视窗跳动。
- 改动落在用户当前视窗**上方**时，锚点不变 → 视窗不跳；改动**正好是用户在读的这一段**时，阅读器会就地刷新 → 用户能实时看见这一段「长出来 / 变了样」。
- 多段要改就逐段重复（一次一段、各自精确 `old`），不要一个 edit 吞掉跨多段的大块。
- `old` 必须在全文唯一；不唯一就把锚点注释一起带进 `old`（如 `"<!-- @anchor: a042 -->\n他推开门，屋里一片漆黑。"`）确保只命中目标段。

## 4. 收尾

每改一段，阅读器会自动局部刷新。全部做完用纯文本说明：改了第几章哪几段、扩写前后大致字数变化，请用户在阅读器查看。
忠于原著：扩写/改写都要贴合上下文的人物、语气、世界观，不要引入与原文冲突的设定。
