# 聊天回忆漫画（chat-to-comic）

当用户说「把我们这段聊天画成漫画 / 四格」「把刚才那个名场面画出来」「给这段对话出张回忆卡」之类时，按本技能做。
适用两种会话：**角色聊天**（酒馆世界）与**伴侣聊天**（companion，本次运行已授权其家目录时）。
产出是图片文件；**聊天转录一个字都不许动**（不 edit、不 append、不往对话里插图）。

> **本机提示词模板复用**：用户要求用已导入/保存/自己的画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，按 `templates.py list → show` 完整查看；只有 `kind=image` 模板才传给 `generate_image.py --template <id>`，参考图说明可用 `--reference-notes`。

## 1. 拿到聊天素材

**「刚才 / 最近这段」**：优先用**当前对话上下文里已有的消息**——你就在这段对话里，不需要读任何文件；读文件只用于翻更早的历史。

**角色聊天翻旧史**：转录在该角色世界的 `chats/` 目录（`main.md` 是当前会话，`main-archived-*.md` 是归档会话）。

调用 read 工具：path=`/foreverse/assets/worlds/<worldId>/chats`

再 read 目标会话文件。格式是锚点段：`<!-- @anchor: aNNN kind=user|assistant speaker=<名> ts=… -->` + 消息正文。**read 从文件头开始**，长聊天要「最近的」别从头翻：先 read 一小窗看截断提示估出文件总长，直接给大 `offset` 读**尾窗**，没找到再向前退一窗。

**伴侣聊天**：优先用当前对话上下文；辅助素材在你的家目录（`/foreverse/companions/<id>/`）：`highlights.jsonl`（用户收藏的高光原话，**首选**——用户亲手收藏的就是他心中的名场面）、`journal/`（互动流水）、记忆与 persona。**家目录里没有完整聊天转录**：要画的旧时刻既不在上下文也不在 highlights 时，直接请用户把那段话贴给你或先去聊天里收藏高光，不要凭记忆编。

## 2. 选时刻，剧本化（本技能的关键一步）

- 用户点名了时刻就用他的；没点名就从对话里挑 **1–4 个情绪峰值**（告白/爆笑/争吵和好/初见），选完用一句话各自复述给用户看（自动模式直接继续）。
- RP 原文不能直接当生图 prompt（满是心理描写、旁白、格式符号，直出必然图文不符）。先把每个时刻**改写成一句干净的画面描述**：谁（外观锚点）+ **单一动作**/表情 + 场景 + 光线氛围。丢掉引号动作星号、系统词、OOC 内容。
- **一格只写一个瞬间**（实测一格塞两个动作会被画成并排双镜头，版式失控）；情绪符号可以写（头顶爱心泡泡/炸出惊叹号/飞出小星星，实测很出效果）。
- 形态二选一：多时刻 → **一张竖版四格**（一格一个时刻，按时间序，起承转合）；单时刻 → **一张单图回忆卡**。

## 3. 形象锚定（按优先级取参考图）

- **参考图来源（按优先级取；`--ref` 可重复给多张**——双人同框把两个角色的头像/立绘都带上，模型支持 ×4（gpt-image-1 / gemini-3-image 类）；只吃 ×1 的模型给最主要那张**）**：
  1. **用户上传**：先问「有没有想用的角色图/自己喜欢的画风图？」用户点输入框 `+` 上传后，图落在 `/foreverse/uploads/<会话>/`（只读），用户消息里带具体路径，直接当 `--ref`。
  2. **角色卡头像 / 伴侣头像**：角色库卡目录或家目录里的 avatar/立绘图片文件。
  3. **网络直链**：用户给 http(s) 图片直链 → `python /foreverse/skills/illustrate-novel/scripts/web_fetch.py --url <直链>`（**别带 `--out` 硬编扩展名**：脚本按真实 content-type 自动落 `/workspace/download-*.<ext>`，拿 stdout `saved=` 当 `--ref`）。**需要登录的网盘分享页打不开**，如实告知，请其转直链或上传。
  4. 都没有 → 纯靠文字锚点块。
- **角色锚点块**：从卡面 Description / persona.md 提炼（发型发色/瞳色/体型/服装主件+主配色/标志物，只写视觉事实）写进 prompt；有参考图时锚点块也要带（图+文双锚最稳）。
- **用户形象**：默认画成**背影 / 侧影 / 越肩视角**（对话里通常没有用户外观设定，不要凭空捏脸）；用户提供了自己的形象设定/照片才画正脸，且照片仅限其本人有权使用的。
- **真人红线**：要求画成某真实明星的脸 → 拒绝并说明；只画原创形象。

## 4. 模型能力自检（必做，模型自己不会知道）

参考图要生效，图像模型必须支持图生图/编辑——**生成前无从得知，模型也不会自己报告**。第一次生图后看 stdout `model=` 对照：

- **吃参考图**：gpt-image-1、gpt-4o-image、gemini-2.5-flash-image、gemini-3-*-image、flux-kontext / flux-edit、wanx-image-edit、wanx2.5-i2i、qwen-vl-image-edit、seedream-4+、seededit（gpt-image-1 / gemini-3-*-image ×4 张，flux-kontext / wanx-image-edit ×1）。
- **不在上表**：`--ref` 被静默忽略（stdout 会给 `warning=` 提示）。必须告知用户：「当前图像模型 <model> 不支持参考图，人物长相只能靠文字描述、和头像未必像；建议换支持图生图的模型，或接受现状」。
- **换模型不用去设置页**：`generate_image.py --model <id>` 对本次任务显式指定；找不到时 stdout 回列可用模型清单。
- **网络不可达 ≠ 模型不行**：生图连续 transport/超时失败，大概率是该 provider 域名在当前网络不可达。重试 1 次仍失败 → `--model` 换一家不同域名的图像模型，收尾说明换了什么、为什么。

## 5. 生成

prompt 四段拼装：**画风**（默认「Q版四格漫画风格，二头身chibi，圆润线条，明快色彩，表情夸张可爱」；用户要写实感可换「彩色恋爱漫画风格，柔和光影，细腻表情，干净线条」）→ **布局**（「竖版四格漫画，从上到下恰好4格等高，每格只画一个瞬间，格间白色沟槽」或「单幅回忆卡构图」）→ **逐格画面描述** → **锚点块 + 一致性约束**（「与参考图同一个人（Q版化也要同发色发型同服装同标志物）」）+ **负面尾串（逐字）**：「画面中不要出现任何文字、字母、对白气泡、拟声词、水印、logo、平台标识、页码、署名」（实测不带会自发画伪平台水印/页码）。

调用 exec 工具，command：

```
python /foreverse/scripts/generate_image.py --prompt "<四段拼装>" --aspect 2:3 --ref <角色甲参考图> --ref <角色乙参考图> --out /foreverse/assets/media/generated/images/memory-<slug>-<yyyyMMdd>.png
```

用户要求沿用自己的/社区画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，用
`templates.py list --kind image → show` 看完模板，再给每页命令加同一个 `--template <templateId>`。
模板包装的是上述四段裸描述；`kind=planner` 不能直接传入。模板版本变化被拒时重新 show，不能去掉模板偷偷降级。

- 四格用 `--aspect 2:3`（竖版），单卡用 `--aspect 1:1`。
- **`--out` 一次到位**：图片是二进制，生成后没有工具能跨目录搬运（write/edit 只写文本，python 摸不到虚拟路径）；想让图落在哪就在生图这一步用 `--out` 直接写到哪。
- 伴侣会话可把 `--out` 落自己家的**根目录**（如 `/foreverse/companions/<id>/memory-20260709.png`；家目录只有根层与 `stickers/` 收图），之后做纪念册（companion-scrapbook）可以引用它。
- 角色聊天想让图随该角色世界保存：`--out` 落 `/foreverse/assets/worlds/<worldId>/assets/images/memories/…`。

## 6. 质检与收尾

Agent 看不到成图，**不要自称已确认画面**。把质检点交给用户：①格数对不对（实测四格偶发被画成 3 格）②四角有无杂字/伪水印 ③人物和头像像不像。哪格不对就改那格描述重生成（`--out` 同名覆盖）；四格数错就在布局段加重「恰好4格等高」再来一次。

纯文本汇报：画了哪（几）个时刻、四格还是单卡、文件路径（伴侣会话里直接把路径发给用户，App 会渲染成可点开的文件）。生成会产生模型费用，一次任务默认 ≤2 张，用户要更多再加。

## 硬规则

- **聊天记录神圣**：不 edit / 不 append 任何转录与记忆文件；产出只落图片文件。
- **取材真实**：画面必须来自对话里真实发生的内容，不虚构没聊过的情节（可以做合理的视觉具象化，不能编新剧情）。
- **隐私**：图不含用户真实姓名/聊天原文长段文字；分享与否由用户决定。
