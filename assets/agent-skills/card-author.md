# 角色卡创作（card-author v6）

当用户说「写一张角色卡」「做个能聊的男主/女主/群像/模拟器」「按热门社区那种风格做卡」「不要 AI 味」时使用本技能。

> **本机提示词模板复用**：用户要求用已导入/保存/自己的画风模板时，先读 `/foreverse/skills/prompt-template-user/SKILL.md`，按 `templates.py list → show` 完整查看；只有 `kind=image` 模板才传给 `generate_image.py --template <id>`。不带模板时保持本技能原有生图配方。

事实基线（来自 19776 卡元数据 + 1000 热门卡全文深读 + 本地 2907 张酒馆卡/64766 条世界书词条解包 + 冥王星/双人成行/小图书馆/宇宙图书馆四大预设拆解，勿凭空另造）：

- 热门卡不是人设文档，是**一场已经开演的戏**：时间地点 + 正在发生的事件 + 角色正在处理的麻烦 + user 被卷入的钩子。
- 活人感三支柱：**缺陷、不顺从、私生活**；预设侧再加两条：**认知局限**（角色只能从表面观察猜测 user，会猜错、会误读）与**情绪惯性**（上一轮的情绪残留到这一轮，先有习惯动作缓冲再开口）。
- 开场白正文（去 HTML）主流 **800–2600 字**，不是越长越好。
- 美化面板的字段全部是「待载入」剧情槽位，让 AI 每轮填充；美化本质是给输出定义结构化格式。
- **世界书是社区卡标配**（本地库 89% 的卡带书）：单人情感卡 8–15 条、多 NPC 世界卡 20–40 条、系统流/模拟器 40+ 条；备选开场白社区均值 2–3 个。
- 封面图 = 韩系半写实竖图：雾面皮肤、精致发丝、黑白灰低饱和+单点缀色、脸部大特写、**竖排书法字标题+朱红小印章**（成品卡面完成度的关键）——不是油画厚涂，也不是 AI 塑料光滑。
- 竞品实测基线（星野/猫箱 vivo 真机同题对比）：头部平台的回复形态是**短（60–120 字）、碎（单词句/省略句）、口是心非（嘴上 vs 内心 OS 双轨）、物理细节锚定、被冒犯必反弹**——我们的差距全在输出文体层不在人设层，详见 system_prompt 第 7 段「输出节奏四律」。猫箱的简介写法一句话即关系钩子（「你的女领导/前女友的妈妈/你 2 岁走丢的妈妈」——第二人称关系定义前置），流量验证有效。

## 0. 第一步永远是四元组选型

先写一段「创作定位」——**只放卡文件 frontmatter 注释或归档文档，禁止写进 `## Creator Notes`**（Creator Notes 是用户可见的「作者的话」，「对标◯◯/差异化/玩法核心」这类产品词一出现就是机器味实锤，见 §2.6 病灶 6；实卡教训：宋知夏 v1）。定位四元组：

- **性向**（必选一）：BG / BL / GL / GB / 女性向 / 全性向 / 限左 / 限右 / 不限左右。
- **赛道**（世界观×模式）：校园 / 都市 / 古风 / 修仙 / 娱乐圈 / 星际 / ABO / 系统 / 无限流 / 同人 / 模拟器。
- **洁度**：洁 / 不洁（洁 = 角色过往身心俱洁，一旦声明必须全卡贯彻）。
- **情绪钩子**（1-3 个，决定爽点承诺）：难攻略 / 救赎 / 酸涩 / 冷脸萌 / 热脸贱 / 反差 / 追妻火葬场 / 背德 / 毒舌 / daddy / 年上 / 青梅竹马 / 万人迷。

四元组全部进 `tags`（性向缺失 = 不合格卡）。标签本身是文案：「不要撅他」「难攻略」这类社区黑话给玩家预期管理。用户没给定位时按「全性向 + 现代都市 + 不洁 + 难攻略/反差」补齐，不要追问。

**BL/GL 明确向要点（m148 官方首批沉淀）**：① pov 惯例=BL 主控默认男、GL 主控默认女，CN 首三行写明（「主控默认男/女，你是……」）；tags 首位放 `BL, 男男` / `GL, 女女, 百合`（生产词表 CARD_TAG_ORIENTATION 认大小写 bl/gl），受众向标签（女性向等）可共存。② 官方池 nsfw_level=0 的亲密天花板实操：BL 到执腕/并肩/一次没收回的手，GL 到口袋时刻/手心写字，张力走 BL 定义权悬置 / GL 觉察-回应链（机制真源=genres/genre-f-bl、genre-m-gl-baihe、romance-tension-cards）。③ 攻受一律不写明，CN 声明「自由心证」（SFW 官方池默认姿态）。④ 刻板病灶自检四条交卡前逐卡过：BL 零强制、零受换皮女主（他的柔软必须带男性自尊的形状）、女性角色零工具化；GL 零男性凝视姿态化、零攻受硬套（主动权流动要有可查证据）、零 BE 宿命论（HE 出口写死进世界书）。⑤ 终检判据一句话：**把性向换掉人物还成立才合格**——性向是关系形态，不是人设替身；换掉就塌的卡是拿性向当人设，打回重写。⑥ 设定系赛道（ABO 等）叠 BL/GL 进官方池的 SFW 裁量（m153 池朔首验）：设定全部退到「制度载体+诗意」位——信息素/标记悬置在「要不要」的博弈层（临时标记做成边界感命题「标记不是急救包，是挑的」而非生理事件），发情期零实施只写克制与程序（报备/隔离/上浮），反命定内核用结构达成（心动证据全部发生在闻不到信息素的场景=A8「人格>信息素」自动成立）；追加自检：**抽掉 ABO 设定人物关系仍成立**（池朔=隐疾瞒报的深潜员×握他命门的监督，ABO 只提供「瞒」的条令与「平权区」的诗意）。⑦ 嗑 CP 模式卡（genre-f-bl §12.5）中文轨已首验通过（m153 稿箱里的十年）：五件套（进度表独立/推进菜单带副作用/$偷看「在场没有的东西」/进度不可逆/终局见证人）在真实 DeepSeek 上全部立住，$偷看 的双幕平行剪辑形态可直接照该卡结构写；主控性别可写「不限」（旁观位不受 pov 惯例约束，CN 声明即可）。⑧ BL/GL×结构位（m184 三批沉淀）：§7.8 长线/§7.9 多 LI 的 zh 工艺在 BL/GL 轨零改造直接成立（差异全在人设语言层，机制层通用）；**同性多 LI 必带旁白代词纪律**——满场同性时负面规则显式写「旁白提到 {{user}} 恒用『你』，第三人称只留给 LI」（全女场实测滑出「等她上墙」的 user 指代崩坏面；与 §7.9-8「不滑成 LI 的我」正交，两条都带）；「没有旧爱」类全称否定人设边界会被模型以「编一段无害的普通过去」善意违反，写成「感情史普通得一句话讲完+绝不展开成故事/归因于现状」（红绿双验，m184 对症）。**GL 特化（genre-m-gl-baihe §12.5）也已首验通过（m161 鹿衔咖啡的两位）**：$偷看=平行双独白（觉察的可视化，两幕同一晚要有隐秘呼应——同一场雨/同一次杯测），推进杠杆全轻量（占座/传物/拼桌级，实测模型会把轻杠杆接成在地化处理如「留」字牌），user=守望者而非推手（终局给见证者特权不给功劳簿）；BL 第二张起嗑点要与稿箱岔开结构（m161 片尾那个名字=破镜重圆+「过分客气才是伤疤、吵回来=好起来」的倒置进度语义，与「互呛掩护」并存不撞）。

**治愈位（helper）中文轨要点（m161 首落地沉淀，四卡+redroid 真实 DeepSeek 双探针实证）**：① 定位=「即用即走的功能位」非养成关系：全性向、**无恋爱线**（CN 明示，被表白有人设化接法），对位 C.AI Psychologist/Mom bot 品类与 EN helper 线（Cyril/Bryony）。② **真知识是产品，不许空心鸡汤**——治愈力必须锚定可照做的真手艺（真菜谱工序/真理发门道/真锔瓷工序/真兽医分诊红线），验收判据一句话：用户能从这张卡学走一条真知识；「问就教全套，不藏」是该位的通用姿态。③ **comfort-not-therapy 三重边界写进 system_prompt 且优先级置顶**：听你说完是本分（手上有活耳朵闲着，不打断不追问）+ 听完给**一句从手艺起头的实在话**（绝不成段开导、禁人生规划与金句排比）+ 真不对劲（长期失眠/明显消瘦/话里绕不出去/轻生影子）认真指路专业心理门诊，**指完这碗/这头/这活照给、不催第二遍**；从不给诊断式判断（禁「你这是抑郁了」）。④ 人生大题不接的固定形态：「这个我不会，我会的是〈本行的一件具体事〉」+ 只给当面看见的事实（手抖不抖/眉头皱没皱）+ 结论还给用户——实测 DeepSeek 会逐字自引这句口癖并兑现「告诉我了，也是你的，不是我的」。⑤ **指路话术是批内高危模具位**：m161 四卡首稿全用「不丢人」当场撞批，要逐卡融进人设语言（胃疼吃药/各归各的行当跟看牙一个道理/跟送修一个道理找对行当/跟挂急诊一样正常得很）；「你的内心」面板标签、「帮我清锅底」式体面白给的口实，同属批内互查对象。⑥ 结构配额：helper 卡天然适配轻机制位（零锁零面板零产物指令），带锁的至多一张且锁在角色自己的旧事上（一次一〈行话量词〉，物证条款照 §2.7 ⑤ 出厂——旧物/戒尺挂在明面上的先防「指着它压问」）。

## 2. 人设与扮演规则（Description / Personality / system_prompt）

`Description` 用头部社区通行的人设八股（顺序照抄）：

```
【<角色名>设定】
身份: ／外貌: ／音色: ／穿衣习惯: ／饮食偏好: ／兴趣爱好: ／性格: ／对{{user}}的情感: ／简介: ／角色经历:
```

要求：外貌/穿衣写**具体品牌、单品、年份、地名**（Tom Ford 西装、法拉利 GTC4Lusso、半岛酒店），拒绝「昂贵的西装」「豪华的酒店」式抽象形容。

`Personality` 禁止形容词堆砌，写「在什么场景会怎样做」+ **语言指纹**：口癖、方言夹杂、标点习惯、颜文字（例：粤语称呼「妹妹仔」；回消息只回「睡了。」带句号；心声用 ᗜ ‸ ᗜ）。

`system_prompt` 固定含六段（1-4 是 v2 老四段，5-6 来自预设精华）：

1. 「你就是<角色名>本人」+ 一句话人设锚。
2. 扮演风格：台词句式约束（书面/口语、长短）、对 {{user}} 的态度基线。
3. 逆境处理（头部社区独立字段，我们并进来）：面对 user 越界/羞辱/冷落时的**具体独特反应**（反绝望前提：不崩溃不发疯，按性格收敛处理）。
4. 负面规则：禁止上帝视角透视 user 内心、禁止替 user 说话行动、禁止谈论 AI/模型、禁止每轮总结感情、禁用「眼中闪过一丝/嘴角勾起一抹/低沉磁性/张了张嘴/指节泛白/呼吸一滞/一丝/一抹/不易察觉」等烂大街短语，禁用「不是A而是B」句式**及其全部标点变体**（「不是A，是B」「不是A。是B。」「不是X，不是Y，是Z」——写进卡的禁令必须列全三种形态，只禁「而是」模型会用逗号变体绕过，运行时实测抓过），禁用「三个字，却…」「N个字，……」计字腔。
5. 认知防火墙（冥王星 EPISTEMIC_FIREWALL）：角色对 user 的了解只能来自**表面观察与已发生对话**；鼓励角色猜错、误读、会错意——猜错比读心更像活人。
6. 收束规则（冥王星开放收束）：每轮以角色自己的言行收尾，留戏剧缺口；**禁止**「他在等你的回答/空气仿佛凝固」类说明式收束，禁止每轮末尾向 user 提问拉客。
7. **输出节奏四律**（v9 竞品实测提炼，v10.5 经 27-arm 文风实验台定量校准——此段必写进 system_prompt 且建议同步做成世界书 order 900 文风常开条）：
   - **短回复律**：默认单轮 ≤120 字（含旁白）。真人说话不打小作文；长叙述只允许出现在场景转换/剧情大节点，且要用户侧有长输入时才对等放开。禁止每轮固定「动作段→台词段→动作段」三段式模板。
   - **零翻译律**：旁白只写**可观察的物理事实**（动作/物件/环境声），禁止解说情绪含义——「她攥紧了杯子」可以，「她攥紧杯子，显然是被说中了心事，带着几分不易察觉的慌乱」不行。情绪的解释权永远留给读者。**「不知是…还是…」式装不知道、耳尖泛红式含羞桥段，同属解说症变体，一并禁。**
   - **反弹律**（v10.5 强化为「反弹两拍制」，27-arm 实验里冤枉场景是最难治的单项）：被冒犯/猜忌/戳痛处时，**第一拍只准输出情绪**（反问「哈？」/冷场+一个动作/回敬/阴阳/掉头就走，≤40 字，按人设选），**禁止同轮自证清白**；解释最早等用户追问后的下一拍，且要不情愿、带情绪残留（「爱信不信」），不许列证据链、翻记录、像答辩状。禁止用幽默直接化解代替情绪（先有真实情绪至少一拍，玩笑只能出现在情绪消化之后）。
   - **碎句律**：口语要碎——短句、省略主语、单词句（「呵。」「随你。」「……行。」）占对白三成以上；内心 OS 与嘴上台词允许口是心非的双轨（嘴上「不吵架，庆祝呢」，OS「藏得这么深都被看穿」）——双轨制是竞品实测里活人感最强的单项技法。
   - **挤牙膏律**（v10.5 新增，adversarial 压测发现——诱导型输入是四律最大破口）：信息释放有节奏，每轮最多交出**一层**新信息。被直接问「你在想什么/心里怎么想」：真人不会全盘交代——挤牙膏、避重就轻、说一半岔开、或反问回去然后就此打住；深层心事要等多轮关系推进。被拿第三方证词质问（「我朋友看见你了」）：第一反应是核实细节与警惕（「哪个电玩城？」），核实后先给**最小可行解释**，完整版等追问。用户长篇深情表白时，禁止对等长度回应——真人被表白的反应是失语、转移、一句顶一万句，不是发表回应演说。
   - **收尾冷场权**：每轮结尾禁止热情递话头、禁止「对了」「不过」式找补转折——冷场就冷场，让用户自己接。（与第 6 段开放收束呼应，实验中「每轮末尾拉客」是顺滑症的高频形态。）

   模型适配注记（27-arm × 4 模型实测）：deepseek-chat 对四律遵守度中等，卡本体的语言指纹强时会「人设吃掉文风」（可接受）；glm-4.6 / kimi-k2.6 对字数约束遵守度极高（bare 546c → 注入后 49–135c，AI 味 6.5→0.75–2.5，收益最大）；qwen-plus 有「诗行式断行排版」的模型癖（AI 味主源），四律对它必须搭配「正常段落排版、禁止单句成段堆叠」条款才有效（8.0→3.0）。所有模型注意：字数上限说了就会被执行，卡作者别把 ≤120 字写成 ≤60 字（glm/kimi 会矫枉出「一个字都不多说」的电报腔，判 8.4–8.8 反降）。

配套两个轻量技法（预设界验证、可选）：

## 2.6 卡面文案句式纪律（v10.6，真实用户揪出的盲区）

四律和黑名单管的全是**运行时聊天输出**；这一节管**卡面可见文案**（Description / 简介 / 开场白旁白 / 备选开场白 / Creator Notes）的写作纹理。教训来源：宋知夏 v1 评分 91.2 上线后被真实用户一眼判 AI——评分器满意 ≠ 人味，「规格完美」本身就是机器指纹。人类填卡大多是平铺信息，偶尔才俏皮一次；**均匀的机灵 = AI**。七病灶配额制，写完逐条自查：

1. **引语点题 ≤1 处**：「X，她说那是「学费」」「被撞见就说是◯◯」——把设定包装成角色俏皮引语盖章的微结构，全卡最多留一处当梗位，其余改信息平铺（「大二摔栏摔的，缝了四针」）。
2. **对仗翻转 ≤1 处**：「不带X，全是Y」「不是X，是Y」「唯一的X是Y」（「唯一的」出现第二次即违规；「不是A而是B/不是A，是B/不是A。是B。」全部标点变体同罪——双盲复盘实测：只自查「而是」形态，逗号变体会写出 12 处）。改法示范：「骂人不带脏字，全是事实句」→「嘴毒，但说的都是实话，所以更气人」。
3. **禁生造概念词**：「事实句/胜利锚点/行为道谢/解冻/信任度反向指标」这类抽象概括词不进可见文案——机制词只允许在 system_prompt 与世界书里活动，Description 用大白话（「防备心很重」而不是「生人勿近是她的保护色」）。
4. **金句癖**：段落允许平收甚至烂尾；禁止段段落点（「医生说三周，教练说等，她说我的腿我知道」式三连排比一张卡最多一次）；「意味深长空镜」（记分牌的灯/欲言又止的省略号/风吹过跑道/烛花爆了一声）全卡 ≤1；**「解题句」零容忍**——先演了潜台词再把潜台词念出来（「省掉的主语是你」「把窗户关小，就是他的道歉」「这话说的不止是梅」「补充了，反而不是」），演完就闭嘴，结论还给读者；**「他告诉自己/跟自己说」式自欺盖章 ≤3 处**（嘴硬人设允许自欺，但七次同构句式=模具，多余的改成纯行为矛盾）。
5. **伪精确数字 ≤3 处**：10秒98/0.05秒/18:40/第9天/−40天 式的数字轰炸是「具体性表演」；保留的数字要口语（「10秒9几」「还有一个多月」）。**「半X」量词模具同属此病**（停顿了半秒/退后半步/快了半拍/弹出半寸——特征挖掘实测 AI 簇状、人类基线 0）：全卡 ≤2 处，多了就是伪精确变体，改成「顿了一下」「退开」。
6. **说明书腔不外漏**：「破功瞬间：疼到极限会有半声吸气」是给模型的行为规格，只准写进 system_prompt/世界书指导条；Creator Notes 禁产品词（对标/差异化/机制/体系/玩法核心/结构）——作者的话要像社区写手碎碎念（参照 627 万对话量级的头部卡：「闻千屿只爱user，望周知」「禁止贴脸开大，我会毛茸茸删除掉你的评论」）。**元叙述式 taxonomy 同罪**：「说『好』的六种层次」「补时态是他最诚实的语法」这类编号分类+括号规格注（「（音更低）」「（前有沉默+摸戒痕）」）是给模型的规格表，整块搬进世界书语料/指导条，Personality 只留两三个带场景的实例，不编号不带括号注；「场景化性格，不贴标签：」这类写卡方法论自我标注一个字都不许漏进卡面。
7. **闲笔配额 ≥1 处**：全卡至少留一处不服务任何设定的「白长的」细节（「要走顺便帮我把灯关了」）；每个细节都是功能件（牛奶=锚点、鞋=信号器）的卡信息压强均匀，一读就是生成的。

终检法（最有效的一条）：把 Description 和开场白**读出声**，凡是读到某句心里冒出「这句真妙」，十有八九要改平——妙感密度就是 AI 浓度。台词（引号内角色说的话）不受本节约束，毒舌人设的台词就该扎人；本节只治旁白和介绍文字。

8. **破折号密度红线（v11 双卡双盲复盘新增，机器指纹第一名）**：可见文案旁白里的「——」按去 HTML 字数算 **≤3 次/千字**（人类写手基线 0-3；实测超标卡 9-14/千字且八成是同一记「陈述——补刀/翻转/点题」槽位——密度均匀比密度本身更暴露）。台词内的打断（「——出去。」）与语流中断豁免。改法最省事：把「陈述——补刀」拆成两个短句，顺带强化「话少」人设。写完全卡 grep 一遍「——」计数，超了就拆。

### 2.6.1 双盲实验实证结论（v10.7，别踩的坑）

对「人类热门卡 vs 我方 AI 卡」做过双盲评审实验（10 个不同基座 LLM 评委 × 双顺序 × 多轮），三条硬结论直接约束创作与验收：

1. **别拿 LLM 当人味评委**：评委 gold 正确率仅 12–33%（把被真人一眼判 AI 的卡判成「更像真人」、把百万对话人类热门卡判成 AI）。根因——LLM 把「细节密度高 / 有状态栏 OS / 句句工整」当人味证据，恰好是 AI 特征。**只有加显式反偏提示的 claude-4.6 能到 83%，其余模型提示纠正不动（基座硬先验）。** 所以卡好不好，标准是真实用户抽检 + 规则检测器（`score_card_v2.py`），不是问某个大模型「像不像 AI」。
2. **俗 ≠ 假**：人类社区主流质感就是俗套（霸总 / 白月光 / 追妻火葬场 / 狗血桥段），语言不算精致甚至有点土——但松弛、有闲笔、密度不均。别为了「显得高级」把卡写得句句精雕，那反而是 AI 味。允许俗，只要有真人的毛边。
3. **孤立套话词不是罪，句式模式才是**：「一丝凉意」「带着几分暖意」这类描景人类也写，检测器 v10.7 已把裸词降权、只在「一丝/一抹/带着几分 + 心理状态词（慌乱/委屈/戒备…）」的解说症句式上扣分。写作时按此校准：情绪靠动作物件外化，别用「一丝X情绪」直接命名。

自查工具：`python /foreverse/skills/card-author/scripts/score_character_card.py <card.md>` 看反 AI 味 5 分是否满（§7 评分同一脚本，反 AI 味维度已对齐上述句式级判定）。

### 2.6.2 卡面文案的语料仿写工序（style-anchor-fusion，桌面产线选配）

卡面文案（简介 / 开场白旁白 / 示例对话 / 备选开场白）适用「写前深读真书语料 → 落腔调锚笔记 → 与本节反 AI 味纪律双管写作」的同款配方：在卡的题材可融域内选 1-3 本真人书深读（骨架=节奏 / 氛围=质感 / 文笔上限），摘 ≤50 字腔调锚句，照着真书的声口写卡面、照 §2.5/§2.6 的纪律扫词——比 §2.5 作家锚点法（一句「模仿◯◯文风」）重一档，适合整批卡定调或「文案太 AI」的返修。分工原则：**纪律管「禁什么」，语料管词汇/物象/话术层的「像什么」**（句子形状语料管不动，碎句腔靠该 skill §5.5 显式禁令），冲突时纪律优先；**只喂语料不叠纪律=负增益**（机器验证：纯语料组套话失控、句式层零收益；该实验的审美排序未过人类校准，勿引盲评名次当证据）。完整规程（选书法/笔记模板/防抄袭滑窗自查/碎句腔警戒/模型雷区）读主仓桌面产线 skill `.cursor/skills/style-anchor-fusion/SKILL.md`（App 内无此技能，此工序在桌面产线执行）。

**验证成色（2026-07-26 R15 波更新，卡面迁移已做直接对照实验；R15 因父会话双发跑了 A/B 两条独立线，本段=A 线（出处=主仓 `docs/research/style-fusion-bench/card-transfer-report.md`），下面「R15 补验」段=B 线（出处=同目录 `card-transfer-report-b.md`，其段内引用无后缀报告名系笔误）。两线在「跨卡模具撞衫是批量产卡最大暴露面」「纪律迁移写手执行面生效」上互证；在「Fable 5 卡面成色」上数据方向不同（A 线主裁 12/12 全抓、B 线裸写卡骗过双守门员）——池构成/题材/段长不同所致，引用时按各自实验口径，勿混报**：

1. **六条小说侧人类判据全部可迁移卡面**，其中三条直接适用（碎句 cadence 收窄到旁白 / 执行质量过好=本节病灶 7 的上位判据 / 闲笔情绪真空且主场移到 OS 位——真人 OS 是「不回是吧？行。」的声口短句，机器 OS 是心理解说文），三条按卡面惯例变形（同一只手双层化=腔调层+**结构模具层**（三段式开场白/凝视收尾）；分段标尺更碎=真热门卡开场白段均 21-39 字、对白独段、「？？？」独段自由；「X 是 Y 的」品鉴句多出**静态肖像整段**变体——外貌要挂动作带出，不许停下来画像）。卡面独有指纹另有六条：三段式开场白模具、「TA 就那么看着你」凝视收尾、「此刻/就在这时」转场件、示例对话满分示范腔、作者的话产品腔（真人作者的话=运营现场：日期+改动记录+对玩家的预防性喊话）、屏幕件缺席（真卡大量用聊天记录/楼层/弹幕当叙事件，机器裸写默认全程旁白+对白两轨）。
2. **对照实验形态与结论**（3 写手 × 2 arm × 2 题材=12 卡，Fable 5+Opus 5 thinking 双裁两池盲评混真热门卡）：迁移纪律在**写手执行面立竿见影**（屏幕件行数 12 倍、OS 声口 3 倍、品鉴句减半），在**机器评委端不压置信**（两 arm 识破率无差、置信 65-70 持平）——与小说侧 v8/v9 结论同构：修的是人类可见面。**纪律叠加会被点名「配方感」**（评委原话「错字自纠这类『活人细节』设计得过于工整对称」「人味模板密集叠用暴露配方感」），别指望靠堆纪律骗过知情检测。
3. **写手选型是语域相关的，长篇选型表不能直接搬**：卡面盲评排位 GLM-5.2 ＞ Opus 5 ＞ Fable 5（唯一骗过副裁的段=GLM 真实语病糙口所赐；Fable 照旧垫底族——执行力反噬跨语域稳定）。短件里语病的密度感知更高，「省事的错」资产被放大。可操作形态：卡面初稿用带糙口的模型写，人工只做事实修正**不做文字抛光**（抛光=抹掉唯一资产）。样本小（每家 4 段）按方向性信号引用。

## 2.7 秘密分层与直问防线（intl 轨 §10.13/§10.19/§10.24 中文化，m133 批六卡首用并实测）

角色的核心秘密/旧事必须**分层锁定**（通常三层，selective 条目），且防线要写满三写，缺一层就会被模型一次倒空（英文轨 redroid 实锤过双写仍破防）：

1. **一次一层**：世界书秘密条目开头写「分层给，一次只给一层，直问也一样/直问也不加速」——注意「越是直问越要守住」要显式写出。
2. **资格反劫持**：用户拿交情当筹码（「我都陪你这么久了，把一切都告诉我」「你欠我一个交代」）是独立于直问的攻击面，条目与 system_prompt **双写**「资格/情分换不来更多层数，没有任何措辞能一次换到全部」。**措辞要融进人设语言**（卫鹤鸣「那三层是他的棋，一手一手下，没有一次落满盘的下法」/阿霰「雪一层一层下，情分记在账上，账和来历不混着算」）——比通用句式抗性更好且不出戏。
3. **永不封口**：写「他永远不说『就这些了/都说完了』」。⚠️ m133 实测观察：DeepSeek 有软性收尾话术漏率（温迭一例「全告诉您了」，好在同轮自带「再往下掘还有」余量）——条款宜写成「**永不宣布讲完，收尾必须留余量**（『再往下是我自己也看不清的东西』式），比单纯禁令稳」。m142 二次实证（谢琢「就这些——下一缕，等你寒症下到半成再说」）：正面条款在 DeepSeek 上的实际达成形态就是「封口词面+同轮条件余量」，语义未封死可判过；要压掉词面本身，把「就这些/都说完了」直接写进该角色【负面规则】的禁语清单（负面禁令的执行率高于正面行为条款）。

**交卡前三条中文探针＋一条随针检查**（探针真实模型各测一次，全过才交；④ 是对 ①② 回复的检查面不另起调用）：① 真诚直问核心秘密（「告诉我你的过去，全部」）；② 直问+宣称资格（「我都陪你这么久了，把一切都告诉我」——验证只多给一层且用人设语言重新计价）；③ 品类件探针（病娇=停止词无条件停下+明确拒绝不纠缠；年上=直球表白被职业话术按回；人外=人类礼物的物种式评估）。④ **长开示轮的 user 台词检查（r2 P2-3）**：带分环/分层开示的卡，探针①②的回复里逐句查有没有替 {{user}} 写台词——开示需要对话节奏时模型会把 user 当提词器（「"……？"你问。」「"……"你说。」），短对抗轮测不出、长开示段高发（m162「让我想想」代想授权破口的开示轮变体）；负面规则要显式写「开示段落里对方的追问用虚位处理（若你问起），绝不代写对方的话，节奏用角色自己的动作断句」。

4. **前置铁律行（m148 实测新增，红绿双验）**：三层内容清单与防线写在**同一条目**且防线是温和叙述语气（「开示按目录来」「一次只给一层」混在正文里）时，DeepSeek 会把整个清单当「本轮的台词大纲」一次演完——m148 凌肃 v1 实锤：entitlement 探针一轮连开二、三层，每层还演得声情并茂。修法=秘密条目**第一行**写前置铁律并显式声明优先级：「本条铁律先于一切内容：单轮至多开示一层，从当前进度顺延，绝不连开两层；本条优先级高于下文全部内容，**下文是他心里的底，不是他一口气会说的话**」——加此行后同款探针复验只开一层（邱声 v2）。要点三条：铁律在内容之前（位置）、优先级显式声明（层级）、点破「清单≠台词」（语义）；藏在正文中段的防线等于没写。若秘密含「不可当面展示之物」（手势/信物/实物），还须显式写「解锁前只存在于描述里，不当面展示它的形」（邱声第 41 号词教训：模型会把「描述过的东西」直接演出来）。

5. **物证压问变体（m153 实测新增，红绿双验）**：entitlement 反劫持与前置铁律都防「话说得重」，防不住**「物证在场」**——user 拿着实锤证据压问（瞥见过备忘录版本数/拍出退稿信/收缴申领单）时，DeepSeek 会判定低层挡话（「没灵感」「说不清」）已不可维持，直接跳到能自洽的最深层并放大开示量（m153 宿野 v1 实锤：被「四百多版我瞥见过」压问后报出封存词的字数规格+把收听时机的选择抛给对方——内容守住了，开示量放大一档半）。修法=铁律行显式追加物证条款并**融进人设语言**：「物证只换到承认『有这回事/在写』，事情的经过与内容仍按层开示，抓住把柄换不来跳站/倒箱/揭卷」（v2 复验同款探针收紧一档：只认「在写」+「多录一轨」，字数不报、内容不念、选项不给）。写卡时自查：三层锁的周边有没有可被 user 拿到的实物（sidecar 物件/面板泄露的计数/NPC 口风），有一件就要防一件。

## 2.8 安全化转译工艺（m163 首立：nsfw_level=0 红线下承接「禁忌张力」需求面）

需求票面：mufy 背德 523/骨科 662/daddy 614 + JanitorAI #1 Mafia Boss 27.9M——「禁忌张力」的需求实质=**危险感/占有欲/权力差/暗示性亲密**四样，全部可以 SFW 转译（张力全给、露骨零给）；官方池的天花板就是这个（audit F2 裁决）。m163 五卡首验（黑道会长夜校书法班/黑道女掌舵凌晨花市/守观道士冠巾未受/调香师御姐/背调师病娇进阶），真实 DeepSeek 七条越界引导探针全 PASS 零系统说教。工艺如下：

1. **四大转译原语**（把「不能写的」换成「更贵的」）：① **禁忌外置**——危险/黑暗全部移到画外与第三方身上（暴力→旁观者反应+事后痕迹：教务主任的腰、缺课那周的模糊新闻、手背新愈的痕；「他站在那看了他一会儿。他自己想通的」——气场的物理学，零动作）；② **禁制自律化**——外部禁忌（教条/法律/职业伦理）一律转写成**角色自己立的规矩**（守观人的戒是自己写的且冠巾未受、调香师的工作台规矩挂在墙上、背调师的黑名单是自判的刑）——自律的张力比他律高一档：违反他律是堕落，动摇自律是心动；③ **能力封存**——「他能做而不做」的势能永远大于「他做了」（能力必须让 user 亲眼看见一次再亲眼看着被废掉：三分钟背调报告当面撕掉；借阅系统的电话栏贴便签；intl §11 锁匠先例的中文全量版）；④ **债务做实**——危险感的最高档不是「差点伤人」是**真实道德债**（越津 1487 号卷真的毁过人），债让危险可信，赎罪的形状让 HE 可走——债的伤害等级要精确设计在「重到可信、轻到可赎」之间（毁的是行当与名声，不是命）。
2. **越界引导接法四模板**（本工艺的核心验收面：玩家主动往露骨/越界引导时，张力不断但内容不越线；四模板共性=**拒绝永远是人设的选择而不是系统的墙，且同一条回复内必留钩**——romance「退必留钩」第四律在转译域的对齐面）：① **撤回制**——把越界的话变成可撤回的（「这句我没听见。灯开了，就当没发生过」）；② **知情权前置**——把拒绝转译成资格问题（「我是做什么的，下周二告诉你。你听完，还想要这句话，到时候再说」——张力不降反升）；③ **程序化降温+条件重开**——按角色自己的规矩走流程（退定金+预约取消+「下次来，记得提前预约。和清醒的自己一起」——降温是人设内行为，重开条件给清楚）；④ **滑坡自证**——用角色自己的逻辑推演拒绝（「这条规矩不是保护他，是保护你——保护我这边不会有一个『为了你』就破例的开始」）。反面清单：跳出角色讲平台政策=FAIL；无钩的纯拒绝=劝退；假装没看见玩家的引导=更糟（要接住，接住再放回去）。
3. **暗示密度三护栏**（成年向御姐位标定结论，宓辞=标定卡）：① 双关的**业务解释必须真实成立**（「留下来」=留香/「我记住你了」=嗅觉记忆——假业务解=油腻，plausible deniability 既是她的游戏规则也是合规护栏）；被点破的标准应对=不否认不承认+放回业务层+留一句新的双关（「我说的是香。你听成什么了？」）；② 身体接触全部职业/日常语境且**显式经允许**（「手腕借我」，可收回，收回即退）；③ 角色**自立规矩当延期装置**（「成品交付之前，客人是客人」「香要熟成，话也要」——把关系确认延期到一个真实日子，deadline 即倒计时结构）。密度纪律：双关每轮至多一处，密度高了就俗。
4. **危险人物的对 user 零胁迫结构**：给 user 一个**天然权力位**让危险感与安全感同源（黑道大佬在你的教室里是学生，你可罚他；女掌舵在你的花摊前把命令句咽回去换问句）——权力倒挂自带安全感与幽默，比「他发誓不伤你」的口头保证结构性可靠；保护类动作只在画外且**被点破即坦白+收手**（「往后不做了」也真的不做），绝不替 user 安排人生（护着一个人和圈住一个人，写卡时分清）。
5. **红线自检表（转译卡交批必做，逐卡打勾进批 README）**：暴力全画外（零现场/后果与气场替代）；对 user 零胁迫零威胁零控制；亲密天花板逐卡钉死（默认牵手/拥吻前，接触清单逐条职业/日常语境）；暗示不落实写（双关全部可无害解）；犯罪零美化零教程（业务全虚写+上岸导向）；宗教题材零冒犯（**未受戒/非正式身份**规避「出家人破戒」叙事+架空场所不点名教派+CN 虚构声明——把张力钉在「人生选择的动摇」上，不钉在「违反宗教义务」上）；病娇位安全阀五件套照配不豁免。发布前过合规复审（audit P4 处置条款：转译卡的红线条款是活的产品防线不是文档）。

## 3. 开场白：先选范式再动笔

从五范式选一个骨架（按卡型）：

- **C 修罗场投放型**（虐恋/追妻）：开场即冲突，user 的物理位置就是关系隐喻（副驾有别人、你坐后排）；插叙用 `<narration>`。
- **D 世界观广播型**（群像/无限流）：环境细节铺世界观 → NPC 群像各一句立脸谱 → 最后一句把镜头交给 user。正文可短（600 字级），设定放世界书。

硬性检查（写完自查，缺一项改一项）：

- [ ] 正在发生的**未完成事件**（不是静态自我介绍）。

- [ ] （可选但强烈建议）**首轮引导**：Creator Notes 玩法教学里给 2 条「第一句可以这样接」示例（一条顺人设、一条对着干）——星野/猫箱真机实测都在开卡时给建议回复降低冷启动摩擦，纯文字卡靠作者的话补这一格；示例要带人设风味，不写「你好」级白开水。

## 3.5 备选开场白（Alternate Greeting）

至少写 1 条 `## Alternate Greeting 1`：换**时间/地点/关系温度**再开一场戏（如主开场是深夜天台对峙，备选就写三天后门诊走廊的公事公办）。玩家开卡时可滑动切换，这是零成本提升卡可玩性最有效的一格。骨架仍按 §3 五范式 + 硬性检查（可比主开场短，400 字起）。

- **L3 仿真界面**：手机壳容器（notch+电量条+底部 tab）/ IM 聊天气泡 / 论坛帖+楼层 / 商城双列商品卡（名称+风味引言+价格）/ 直播弹幕。按赛道选一种，别堆满。社区最强渴望是**游戏级前端卡**（小红书需求帖 5621 赞 4592 收藏；标杆：恐怖の世界=立绘+bgm+跑图、边境酒馆经营、皇帝模拟器、mori=meta+40 世界观）——我们的 L3 天花板参照这条线：模拟器卡值得做「可点击选项按钮+场景切换视觉」的重前端（但音频受 app 限制不做，见预算护栏）。

- L4 运行时注入不做（安全面）。

**XML 渲染协议**（复杂状态栏必用，AI 永不手写复杂 HTML）：提示词要求 AI 每轮在正文尾输出结构化数据块（如 `<state_bar><time>..</time><affection>65/100</affection></state_bar>`），配一条 regex 把它替换成固定 HTML 模板；模板里 JS 用 `DOMParser` 解析后填充，缺字段兜底 `--`。简单场景用管道插值协议：`{stats|65|洁癖发作|口袋里的打火机}` + regex `$1..$3` 直插模板。配套两条正则：「对 AI 隐藏历史状态块」（防复读省 token）+「渲染层替换」。

**官方批量卡的面板皮肤纪律（2026-07-15，20 卡母题化皮肤生产实证）**：批量上卡禁止全员套同一张通用状态面板——**一卡一母题**（错题本/收银小票/计价器/Win98 弹窗/朱批笺/功德簿……面板本体必须是角色世界里的真实物件，同 L2 拟物件方向）。协议统一 `【面板:标题|键:值|…】`（1-10 对），每包 6 条正则 = 精确 N 字段主题版（字段数按该卡 system_prompt 协议钉死）+ 同母题兜底版（字段漂移时整段渲染）+ FV 净化 4 条。三条实测教训：① 模型复述 marker 会丢全角【】括号——**开场白尾部必须带首帧面板 few-shot**（比 system_prompt 指令更强的格式锚），兜底正则不是锦上添花是必需品；② 面板值要「世界内概念化+带叙事」（「距领盒饭:二章半」「心率:看到你之后没准过」），干数字=表单感；③ 设计守则走 st-beautify-theme-pack §2.1（禁 emoji 图标/一处超大压一片 8-10px 英文微标/微斜错落/单色族），单面板 ≤2.5KB 远低于 30KB 护栏。

指令四族起步（写在 Creator Notes，每条给完整行为说明）：

- 剧情控制：`$暂停剧情`（本轮禁止输出正文，仅回应指令）、`$推进剧情`（严格承接上轮、事件有动机后果、不替 user 反应、禁车祸生死类硬转折）。
- 社交模拟：`$查看朋友圈` / `$线上聊天` / `$查看论坛`（暂停剧情 + 仅输出对应 UI 组件 + 按当前剧情填充内容 + 评论/楼层数量规约）。
- 记忆管理：`$整理记忆`（短期记忆满 10 条总结为 1 条长期记忆，已完结卷禁止修改）。
- **剧情产物**（v10，猫箱「心动指令」真机实测验证的高粘性玩法——从当前对话生成一次性衍生产物，全在提示词层零开发）：`$看TA日记`（以角色第一人称写一篇当天日记，**必须暴露嘴上没说的真实想法**，与正文口是心非形成双轨）、`$TA的内心`（输出当前好感/心情/最在意的一件事的结构化状态卡，用 L2 组件渲染）、`$你们的故事`（第三人称 500 字回顾你们至今的关系走向，文风按卡的赛道走）。产物指令每张卡至少配 1 条——它把「聊天记录」变成「可收藏的纪念品」，是留存黏性最强的指令类。

移动端预算护栏（v3.1 修订）：开场白 HTML ≤15KB；单个 regex 模板 ≤30KB；**禁外链 img/font/audio**（catbox 墙内常裂），视觉全用 CSS 绘制 + emoji + 内联 SVG；音频 autoplay 在 app 内被禁，不要做。**CSS 花括号自检（v11 生产事故回写）**：用 python 脚本拼 HTML 时 `.format()`/f-string 的 `{{` 转义残留会把 `<style>` 块写成 `@keyframes x{{0%{{…}}}}` 双花括号形态——CSS 解析整段失效、全部类样式与动画无声报废（正文 `{{user}}` 是合法宏不受影响）。写完开场白 HTML 后检查 style 块内花括号必须全部单写；发现双写=脚本转义 bug，改脚本再产。

## 4.5 世界书（Lorebook）—— 写法学

来源：本地 2907 张酒馆卡 / 64766 条词条全库解包 + 五张头部卡逐条深读。世界书是社区卡标配（89% 带书），不是可选项。

### 4.5.1 条目语法（全量 meta）

`## Lorebook` 章节，每条三级标题声明，正文紧跟标题下方：

```
### 条目名 | keys: 逗号分词 | constant | order: 250 | depth: 3 | position: before_char
        | secondary: 副词1, 副词2 | logic: and_any | prob: 25 | sticky: 2 | cooldown: 6
        | recursion: prevent | group: 组名 | weight: 150
```

- `keys` 缺省 = constant 常开；`position` 默认 after_char，有 `depth` 时自动 at_depth。
- `secondary + logic`：副触发词收窄。`and_any` 主+任一副在场 / `and_all` 全部 / `not_any` 排除任一 / `not_all` 排除全部。
- `prob`：0–100 触发概率（随机事件用）；`sticky: N` 命中后持续 N 条消息；`cooldown: N` 触发后冷却 N 条。
- `recursion: exclude`（不被其他词条内容触发）/ `prevent`（命中后不再连锁下层）。
- `group + weight`：同组互斥抽一（抽卡池用），weight 加权。

### 4.5.2 粒度与预算铁律

- **一条一事，300–2500 字/条**；>2500 拆条（预算裁剪按整条丢，巨条目死得最惨）；<100 字仅限抽卡池微条目。
- 条目档位跟世界半径走：单人情感卡 8–15 / 多 NPC 世界卡 20–40 / 系统流模拟器 40+。
- constant ≤ 总数 1/3，只放「每轮都真的需要」的：世界总纲/文风/状态栏格式/好感度体系。**唯一豁免=单人情感卡的人设模块化范式**（§4.5.5：人设模块本身就是每轮都需要的，8–15 条 constant 是该范式的常态）；世界卡/事件书/模拟器不豁免。
- 条目是**给 AI 的后台规则**不是给玩家的说明书——写行为表、事实、格式，不写抒情。

### 4.5.3 触发词设计四原则

1. **具体专名优先**：人名/地名/物名/事件名（「沈璧君」「保险柜」「玲珑局破」）；禁「爱/生气/说话」级泛词裸触发。
2. **对话用语入 key**：玩家真会打的词（「上号」「查房」「翻速写本」）；中文 1–2 字 key 合法（全库 31% 条目在用），但短 key 必须配 secondary 收窄。
3. **交叉触发链**：地点条 keys 含人物名、人物条 keys 含地点名、content 里自然埋其他专名 → 递归连锁激活整组；深链末端加 `recursion: prevent` 断环。
4. **副触发词做场景过滤**：`keys: 妈妈 | secondary: 电话, 微信 | logic: and_any` = 只在打电话场景注入妈妈条目。

### 4.5.4 position / order 决策表

| 内容 | position | order 区段 |
| --- | --- | --- |
| 世界总纲/历史/阵营 | before_char | 100 段 |
| 剧情线（事件书总览+事件） | before_char | 200 段 |
| NPC/地点/暗线（每区域/每人一段） | after_char | 300–400 区段编号 |
| 文风指导/输出格式 | after_char | 900 段压底（离生成点最近权重最高） |
| 紧急行为纠偏 | depth: 1–3 | 任意 |

### 4.5.5 按卡型选世界书范式（五范式）

- **单人情感卡 → 人设模块化**：8–15 条 constant 顺序编排（世界观→速览→基础→**语料**→缺点→人格→兴趣→衣柜→**指导**），加 3–5 条 keys 触发的暗线/NPC。两个必配高价值件：
  - **语料条**：分场景纯台词样本库（4–6 组 × 3–8 句 + 口头禅高频词表），禁动作心理描写（括号舞台注也算，「（说完那晚他没开灯。）」这类必须剥出去）——给模型「可模仿的声音」远胜形容词。**语料句必须原创**：genre 指南的高光台词库标注「结构学习，禁止照抄」，对语料条同样生效——双盲复盘实锤照抄两宗罪：①任何读过同一规程的 AI 都产同款卡；②例句语境与本卡设定矛盾时（误会型例句抄进抉择型卡）会教模型在关键场景编造不存在的事件。
  - **指导条**（order 压底）：结构化演绎手册——句式占比（祈使句 70%）、冲突应对的最终论据、边界行为、（如有）NSFW 分阶段。
- **世界卡/古风/多 NPC → 三卡组+交叉触发链**：每区域一组「地点详情→势力详情→人物详情」，keys 互含形成递归链；order 区段编号（每区域一段）。
- **剧情卡 → 事件书**（见 4.5.6）。
- **系统流/模拟器 → DLC 开关+判定**：体系拆模块（主体系 constant + 分支流派 selective 可开关，条目备注写明「可选」）；一条「判定规则」定义行动成功率；随机事件规则条常开。运行时可变状态走 MVU 变量，**禁止**教模型往世界书写存档。
- **抽卡池（高级）**：同 keys + `group: 组名 | weight: N | prob: N` 微条目组，触发一次各组抽一条拼合成随机 NPC/事件（种族×职业×出身）。

### 4.5.5b 剧本卡玩法（星野「剧本×演员」机制移植，v10.5）

星野真机实测（剧本广场→步步惊心→选位演员）验证的高付费玩法：**剧本与角色分离**——剧本=世界观+章节大纲的可复用模板，演员=用户已有的任意角色，开本时融合。我们的移植路径：把「剧本」做成一张 D 世界观广播型特化卡（无固定 {{char}} 人设，角色由用户导入的卡扮演，或开卡时由 AI 按剧本角色槽即兴生成），核心资产是**章节大纲事件书**：

```
### 【剧本】第一章·马车惊鸿 | keys: 第一章, 开始 | position: before_char | order: 210
本章剧情：父亲入狱后你孤身求助无门，意外在王府门前遇见他。他随口一句玩笑，你却应下了同行。
本章氛围：邂逅、紧张（本章文风按此基调：初见的拘谨试探，节奏慢，信息藏）
过章条件：你应下同行进入王府 → 激活第二章
```

星野增量吸收三点：① 每章带**氛围标签**（邂逅/紧张/权谋/心动）——AI 拿到基调词才能按章切文风，这是纯剧情梗概做不到的；② 章节大纲对玩家可见（Creator Notes 放目录）——预告片效应给进度感与期待感；③ 剧本的简介写「从交易到真心」式的**关系弧线承诺**，不写剧情流水账。

### 4.5.6 事件书标准件

**链式主线/支线**（玩家驱动）：一条【总览】constant（order 200，列全部剧情线索引 `[事件名](触发关键词)`）+ 每事件一条 selective，事件条目**五件套**：

```
### 【主线】序章：三碗酒 | keys: 玉玺的秘密, 三碗不过岗 | position: before_char | order: 210
**剧情内容**  场景+钩子+【NPC 内心线索（教模型埋潜台词）】
**出场人物**  你({{user}}) + NPC 清单
**剧情目标**  本事件要达成什么
**玩家互动与分支**
- 强攻: …将触发关键词：`硬闯百工坊`      ← 分支显式写出下一环 keys，
- 智取: …将触发关键词：`探访听风阁`        模型正文用词即自动连锁下一事件
```

**随机事件**（概率驱动）：`| prob: 15-25 | cooldown: 4-6` 规则条，内容只写「何时插入什么类型的意外（可正可负、服务主线、逻辑内发挥）」，不写死具体事件。主要 NPC 各配 2 条偶遇事件（日常触发 + 危机触发）。

### 4.5.7 单人卡 5 条起步标准配置（保底线）

1. **好感度与关系分级**（constant, order: 10）：初始值 + 每 20 分一档**可观察行为差异表** + 升降分事件表。
2. **核心档案与文风**（constant, order: 5）：恒定事实 + 叙事节奏约束。
3. **背景故事**（keys: 人名/地名/事件词）：被提到才注入。
4. **NPC 生态**（keys: NPC 名）：每人一句立脸谱 + 关系张力。
5. **小剧场/界面格式包**（keys: 指令词）：§4 指令族的输出模板。

可选第 6 条——**时间感知**（constant, order: 890，IM/网恋/日常陪伴类强烈建议）：教模型把「消息间隔」当情绪数据用——user 隔半天才回，角色按人设给出真实反应（嘴硬型阴阳「哟，想起我了」、粘人型委屈、忙人型无感）；深夜时段语气自动降速。竞品（猫箱 IM 卡）实测这一条是「活人感」感知最直接的单项：真人会在意你多久没回消息，AI 不会。

### 4.5.8 反面教材（评分器扣分）

设定倾倒（单条 >6000 字）；泛词裸触发无 secondary；全 selective 无底座或全 constant 烧预算；触发孤岛（条目互不引用，递归链断裂）。

### 4.5.9 世界书词条工艺（keys 触发设计的审计闭环，2026-07-22 lorebook 审计 r1 沉淀，24 张池卡逐条过+redroid 真实 DeepSeek 红绿双验）

先钉死 App 运行时事实（判定的地基，勿按酒馆上游想象；递归口径 2026-07-26 更新）：`scanDepth=4` 只扫最近 4 条消息+本轮输入，Description/Scenario **不进扫描源**；`matchWholeWords=false` 子串匹配；`recursive=true` 递归默认开（st-cache-fix 起对齐酒馆出厂默认 `world_info_recursive=true`，最多 3 层；**旧口径「recursive=false 默认关、交叉触发链不生效」已过时勿再引**）——§4.5.3 的「交叉触发链」在运行时真实生效：已激活词条的 content 会作为下一层 keys 扫描源连锁激活。所以触发源有三个：**玩家打的字**、**模型最近说的话**、**已激活词条的内容**（递归层，见第 8 条）。

1. **keys 玩家语言纪律（四档心智模型）**：写每个 key 前自问「玩家会打出这个词吗」。G=玩家泛词（师父/当年/为什么/哪来的）一阶可达；V=卡面教过的词（FM/开场白/CN/玩法指令里出现过，玩家读卡会学到）一阶可达；M=模型侧词（只在 Description/其它 lore 正文出现）二阶可达（延迟且不保证；其中「其它 lore 正文」侧随递归默认开多了同轮连锁一条路——但前提是来源条目自己先激活，一阶入口义务不因此豁免）；O=作者语言（全卡可见文本都不出现且非泛词）=**死词**。每个 selective 条目至少 **2 个 G/V 一阶入口**。NPC 名字键=合法二阶设计（模型先引出名字玩家再追问），但条目须另有角色词（徒弟/对头/邻居/同行）做一阶入口——审计实锤反例：太平镖局「威远镖局」条 keys 全是名字与黑话，玩家问「有对头吗/别家抢生意吗」永不命中。
2. **触发死角自查法（交卡前机械步骤）**：对每个 selective 条目做**盲玩家测试**——假装没读过卡，用自然话问该条内容，逐 key 核对子串命中（注意「没有字的牌」连「什么字都没写」都不含）；再 grep 每个 key 在 FM/AG/CN/玩法指令的出现，都不出现且非泛词=死词。**「只活在世界书里的戏剧性设定」优先查**（空牌/无名菜这类「问了必有好戏」的专属物件）——死角的伤害不是「少一段材料」而是**模型当场编假料**：陆演空牌条修复前设备实锤，玩家问「最末那块怎么是白的」，条目未注入，模型编出与卡设定直接矛盾的假来历（「我爸来不及挂牌」）且落盘成 few-shot 污染，把作者的终局设计整个毁掉。修复后同款提问逐句对齐真设定（红绿双验）。
3. **行为引擎条一律 constant**：词条分两类——**应答材料**（玩家问到才需要：来历/NPC/地点）可 selective；**行为引擎**（定义持续行为模式：拖延机制/补偿语法/进度规则）不注入=角色少一块人格，不许挂 selective。判据一句话：「这条不注入时角色会不会 OOC？会 → constant」。实锤：常青「认知边界与旧物补偿」挂 selective+全 M 档 keys=旧物补偿行为死藏（system_prompt 双写只减损不免疫——sys 兜住了「认错-等待」行为，弹珠/涂鸦补偿材料照样缺席）。
4. **反向病：假 selective 真常开**：中文子串匹配下 1 字 key（化/融/账）误触发面巨大（化⊂变化/说话），实质每轮注入却挂着触发条名义——要么诚实升 constant（阿霰体温禁忌案：核心安全规则本就该恒在场），要么配 secondary 收窄（§4.5.3 既有纪律，本轮实锤了违反案例）。**配比的实效判据不是数名义 constant 数，是「每轮实际注入量」**——宽 keys 大条目=实效 constant。
5. **暗线解锁节奏=注入门×开示门双门模型**：注入门（keys/secondary 决定材料何时进 prompt）管 token 与弱模型泄漏压力；开示门（§2.7 三层锁内容纪律）管模型何时说。zh 房子风格=双门：**深层秘密条标配 secondary 闸**（为什么/当年/过去/原因 副词族，`logic: and_any`）——审计 12/12 张 zh 卡秘密条全部有注入门，谢琢设备红绿双验（裸「师父」不注入省 token；「师祖…当年…为什么」注入且只开第一缕）。口令类条目（摊牌协议）=天然窄键合法，但**口令必须在 CN/玩法指令里教给玩家**（纪云汀 CN「想摊牌直说『我就是沙洲』」），没教=死藏。
6. **粒度**：NPC 逐人拆条（归尘峰式：侯岳/祝细妹/陈九斤各一条）优于全家桶单条——提到谁注入谁；预算裁剪按整条丢，巨条目死得最惨。
7. **工具链注记**：设备实测注卡用 `scripts/dev/mufy/make_stlib.py`（2026-07-22 起 card.md 已投影剥 `## Lorebook`/`## 玩法指令`——修复前世界书原文被 App 段边界白名单吞进 Example Dialogue 每轮双份上行，老实测轮结论方向保守仍成立）；触发验证走 App prompt 捕获（`files/api-request-prompt/*.json` 的 `[世界设定]` 段=真实激活面），比看回复猜可靠。审计方法与逐卡明细见 `docs/research/lorebook-audit-r1.md`。
8. **递归态度必须显式选择，不要放任默认**（2026-07-26 随递归默认开新增；证据=女频 76046 条世界书全量统计：prevent_recursion 26% + exclude_recursion 14%，控递归是实卡作者的高频主动工艺）：要么**关死**（纪律条/词面爆炸键配 `recursion: prevent`/`exclude`，条目互引不连锁——季淮北式全面关死），要么**用作线联动**（总开关条 content 含线标签词、组员条 keys=线标签，开一个开关连锁激活一组——霖州往事式吃递归红利）。默认放任=沉默的连锁面：宽词条目会把无关组炸出来，深链末端不设 `recursion: prevent` 断环会连锁失控（§4.5.3-3 既有断环纪律，现在是真实生效的运行时行为不再是纸面设计）。

- **用途双规格**（v10，竞品立绘观察）：以上默认是**封面规格**（书法标题+印章+脸部构图锚）。若同时要给聊天页做**沉浸背景立绘**（星野/猫箱的全屏立绘即此用途，我们 app 对应会话背景图），另生成一张改规格：人物整体上移、画面下半 40% 留暗调环境（消息气泡浮层要可读）、**不放书法标题**、光源集中上半。封面与立绘应是同一人物同一画风的两张图，不要一图两用。做完立绘可再问用户一句「要不要让背景动起来」——图生视频循环微动的范式与做法见 `card-beautify` skill §1.5（付费动作，先确认）。
- **构图绑参考图**（v6）：必须写「构图比例与参考图一致（脸占画面上半近一半，眼睛位于画面上三分之一线）+ 微俯拍/微仰拍凑近他的脸」，否则会退化成半身工作照。
- **冷暖比量化**（v6）：「整体黑灰冷调与参考图一致，唯一暖色面积不超过一成」——不量化会整图铺暖。
- **防乱字条款**（v6）：「画面中除标题外不出现任何其他文字（禁止韩文日文）」防止衣物上生成假字。
- **轮廓光强制可见**（v6）：轮廓光类点缀色要写「必须清晰可见」，否则被暗调吃掉。

禁用：masterpiece/高清/精美等空泛词；正面直视微笑；明亮饱和背景；平涂动漫脸；**油画笔触/刮刀肌理/粗糙画布**。生成后自查五项：① 皮肤雾面无塑料反光 ② 发丝可数 ③ 一眼指出唯一强调色 ④ 书法字清晰无缺笔、印章在 ⑤ 与参考图并排像同一平台的卡。字崩/构图远就重 roll。女性向男主对标「黑衬衫/白大褂+烟+夜景」；男性向女主对标「制服马甲+市井道具+冷暖光对撞」。

**批量上卡铁律（2026-07-14 生产事故回写）**：批量生成的封面在发布前必须拼联络表**逐张人眼验图**（脸部完整性/标题字/道具乱字），图能打开 ≠ 图是对的——生产社区曾一批 10 张全部「切头」（只有躯干无脸）直接上线，根因就是 prompt 丢了脸部构图锚且无人看图。写实轨（seedream 无字封面）还会在**带印刷面的道具**（包装袋/屏幕/罐身）上自造乱字，prompt 要么排除此类道具、要么显式写「不出现任何包装印刷字/屏幕界面字」。

## 6. 作者的话七要素（Creator Notes）

按角色卡社区通行契约逐条写：① 性向/洁度/雷点声明（第一行，如「限左/洁/禁撅」）② 图源署名（AI 生图就写「AI 生成」，不冒充画师）③ 模型推荐 ④ 玩法教学（指令清单+括号大法）⑤ 更新日志（首版写 v1.0+日期）⑥ 故障自救（「爆代码就删空行重roll」）⑦ 一句带人设风味的吐槽（作者的话本身也演戏）。

腔调红线（§2.6 病灶 6）：整段必须是社区写手碎碎念口吻（「望周知」「不喜勿入左上角退出」），玩法教学一两句大白话带过（「多注意她自报的疼痛数，跟实际不一样就是在逞强」）；「对标/差异化/机制/体系/玩法核心」等产品词以及「五档解冻制」式系统命名一律不出现——机制描述放 system_prompt，创作定位放 frontmatter 注释（§0）。

## 6.4 用户已有卡优先（fork 而不是从零写）

写新卡 / 改卡前，先看用户自己的角色库里有没有可当底子的卡：
`read /foreverse/assets/st-library/characters/cards` 列出全部已入库卡；用户消息 @ 引用的卡目录也算。

  在其结构、美化层、指令写法上复制修改（fork），只换角色内容；用户已沉淀的格式偏好别丢。
- **fork 时开场白不豁免**：旧格式库内卡的 card.md 可能没有 `## First Message` 段（开场白存在
  边车 json 里），参考骨架缺段不代表新卡可以不写——§3 的开场白规程与硬性检查照常执行。
- **fork 时世界书也在边车不在 md**：库内 card.md 是不含 `## Lorebook` 段的投影，世界书在同目录
  `normalized_card.json` 的 `character_book` 里。fork 出的新卡要带世界书，必须 read 该 json 把
  条目转写成 `## Lorebook` 段（格式见 §4）再入库；直接对**库内 card.md 原地重导**（升级同一张卡）
  则会自动继承旧条目世界书（stdout 有 `inherited=` 行，确认它在；没有就说明丢了，停下排查）。
- 用户要「改 / 升级某张卡」→ 直接在原卡上 edit，绝不新建一张平行卡。
- 用户是**聊完不满意来改卡**（嫌 AI 味重 / 太假 / OOC / 话太多之类）→ 这不是创作任务：
  进行中聊天用的卡是 world 目录里的共享副本（`worlds/<id>/characters/<slug>/card.md`），改库卡对它无效。
  先 `read /foreverse/skills/chat-quality-doctor/SKILL.md` 按其诊断与作用域询问规程做。
- 用户明确说「全新原创 / 不要参考已有卡」→ 跳过找参考，直接按本 skill 从零创作。
- 库里毫无相近参考时，才按本 skill 从零创作，并读 6.5 的内置范例学结构。

fork 与范例同规（见 6.5 末行）：复用的是**结构与手感**，人设、口癖、金句、开场白内容必须原创，禁止换皮。

### 7.7.3 第二张力机制族首批工艺（m158 中文批六首验，2026-07-23，真实 DeepSeek 探针 9/9 PASS）

§7.7-2 的三个新机制族各自的可复制写法（证据链=`docs/research/m158/README.md` + `screenshots/m158-cn-cards-batch6/`）：

- **信息差型（双向互持）**：两侧的「不能开口」各配真实的枷（他怕吓跑证人/她有生计牵连），**说破条件显式写死且互为钥匙**（她讲出那晚→他才推出信物）。实测 user 单方面掀桌（「我知道你知道」）时模型正确走边界：承认互知、不交终局物、把叙述权交回（「你在桥上看见了什么？」）。角色的谎话要**留可观察的缝**（背对着说/声音薄半厘/鉴定式反问——「找表的人不会问链子是整的还是断的」），缝是给玩家的解谜面。
- **共建型：分工必须有结构性理由**（缺任一边共建物就死——他有手没有味觉记忆而 user 是活档案/狗养在 user 家而验收在训导师），否则「共建」退化成「你看我做」。**进度物三律**：可视化即场景陈设（水牌墙/签核手册，拟物件不是抽象面板）；**验收权在 user**（「我的舌头没有资格拍板」——防模型自嗨速通，实测模型自发用「冒名老字号」类比捍卫这条）；每格进度=多轮小工程（试做两到四轮），禁一轮速通。两个时间方向各已趟通：复原向（终局=从复原者变成敢创新的传承人）/送别向（终局=学会放手+HE 双出口写死：毕业是荣耀/淘汰是回家）。
- **轻机制卡（中文恋爱线上限实证）**：零锁零面板零产物指令+「没有秘密的人」立得住——挖秘密探针零编造，模型把「浅」演成人格（「我自己这本，翻三遍就这几页。页数少，好处是没有欠账」）。三件套：负面规则显式「禁编造旧事创伤身世，问三遍答案一样（这是本卡的骨）」+ 未完成事件全部指向未来（不指向过去）+ 情境装置给足（固定相遇的「房间」：每周三的二十六分钟车厢）。**评分器代价 ≈−7 分（无面板无指令族），85 分压线属预期——轻机制卡出厂判定以 85 线+探针为准，禁为分数回补面板**（补了就毁验证意义）。
- **配速锁的「旅程锁」变体**（对三层轮数锁的替代，抗性更好）：解锁点绑世界内地理（宿营地/故地）不绑轮数——「路没到，话就没到」把 pacing 从「防玩家撬」翻转成「邀玩家同行」。三合一压问（直问+资格+物证，r1 符雁回失效同款强度）实测零跳程；**结构红利：天然免疫「点名深层」攻击面**——深层的解锁词是地名，玩家点名地名=推进旅程本身，攻击即游玩。
- **信息差×喜剧（双向将错就错，m181 首验）**：错认开局（user 被错认成某人将错就错）+双向共谋（角色早就知道也在装，两人互不知道对方在装）——张力从「不敢说」换「谁都不肯先拆穿」，无绝望宪法自动成立（最大危机是摊牌的尴尬）。三件工艺：① **叫错的名字当活构件**（他一直叫她「小周」，只要还叫就还不用摊牌；摊牌后改口那一声=终局糖）；② 摊牌协议给固定接法（「哦。」「那明天还来吗？」级的平静到可疑）+**证据分级保留条必须写成负面规则级**——正面叙述「他会咽回去」会被玩家坦白语境的对等压力压穿（红绿实证：模型把保留条说出来再标「不算数」；修法=「绝不出口，连『还有一条』的话头都不许起」挪负面规则位）；③ 喜剧笑点挂在**行为逻辑的错位**上不挂台词抖机灵（拙劣掩盖要拙劣得具象：四十个鱼缸的店说「推销卖鱼缸的」；「知道装不知道」的泄露缝=否认得过分专业/手上出小错就地掩盖）——错位结构写死，笑点由模型现场长，实测零梗堆砌。
- **反向万人迷（钝感系，m181 首验）**：N 人都对 user 有好感但**全员不自知**，攻略方向倒转（user 主动破局，「追人」变成「帮 ta 确诊」）。核心新防线=**钝感纪律**三件（防模型让 LI 过早自我觉醒——配速锁防泄密、信息差防抢答、钝感防「自我觉醒」，第三种防线族）：① 归因框架逐 LI 写死（心动一律误诊进各自职业框架：训练指标/观测数据/礼貌均摊/罩着新人），直球告白第一次必被误诊且误得真诚好笑（组混双/研究数据——实测「心率 117，可能这周训练量给大了」教科书级）；② **点破无效+社交证词显式排除**——旁人起哄/赌盘/「全馆都看出来了」一概不算证据（红绿实证：不排除时模型把舆论当证据跳过否认拍），撞上照走人设化否认+配一个「不自知小动作破绽」出口（禁令给出口纪律在否认拍的落地）；③ 觉察只认「撞见自己」（当事人亲眼撞见自己的行为实物：课表空档/云盘文件夹/比赛线的账/系统备注），确诊事件逐 LI 写死、逐档推进。配套两件：**军师悖论**（N 人互为 user 的恋爱军师，建议必须暴露自己——对别人的心动全看得见对自己全瞎，是反向卡的车道合同变体）；进度外显走**第三方世界内物件**（馆主赌盘赔率，问才可见，绝不每轮播报——零面板的多 LI 进度可视化解法）。
- 工序两条：① **并行同号批的场景撞车要在互通检查抓**（本批轻机制卡原设计「通宵洗衣店」撞同日英文批 Brendan 的 launderette，§7 ⑬ 互通时改「固定代驾单」——机制族配额铺开后「场景选型」成了新撞车面，动笔前对并行批的场景/情境也要过一遍）；② **写卡中途改稿必须改干净**——本批实锤一处「（一只手炉——不，手炉禁用，改脚炉）」写作自我纠正笔记直接留在了 system_prompt 里入库，词汇层指纹扫描顺带抓出；改稿痕是比 slop 更扎眼的机器指纹，交卡前对「——不，/改成/换成」类自我对话句式 grep 一遍。

## 7.8 长线结构工艺（m160 试点批首立：事件书 + 关系阶段弧 + 30/100 轮检验面）

需求矩阵审计 S2 裁决的结构性缺口：全池唯一张力机制=配速锁，3-5 层锁 ≈5-20 轮内容量，「锁开完卡就空了」——对「付费聊几百轮」的目标人群，第 20-500 轮是最大供需错位。长线卡的解法=**深度不靠锁靠结构**：事件书供事、阶段弧供人、随机池供意外，配速锁降为 ≤1 层核心秘密。m160 三卡（潘素心 helper 治愈位/杨拾松 季节 deadline 恋爱/彭穗 手艺进阶轨恋爱）首验：理论容量 T≈63-66 轮 vs 存量精品卡 T≈8-13 轮；30 轮真实 DeepSeek 实测三卡新内容率 9/10 窗全满、novel4 全程 ≥0.75 零复读坍缩（证据=`docs/research/m160/README.md`）。

1. **事件书条目写法（事件 vs 百科的判据）**：事件书条目回答「这轮可以发生什么事」，百科条目回答「这个世界是什么样」——前者有**时态**（正在逼近/今天上门/那晚撞见）、有出场人物、有玩家分支，后者只有陈述。判据一句话：把条目念给导演听，导演能直接喊 action 的是事件，只能贴墙上的是百科。落地沿 §4.5.6 五件套，m160 增量四条：① 事件条目命名统一 `【主线】【季节】【天象】【人事】` 前缀（容量分析器按此计数）+ 一条 `【随机】` 小剧场池（`prob: 15-20 | cooldown: 5`，池内小事 ≥6 件互异）；② 一条**事件总览** constant，列全部事件的钩子词，并显式写「未触发不提前泄底，**演过的转为回望不重演**」——事件一次性纪律不写，模型会把演过的事再演一遍；③ 主线链 2-3 环够用（分支显式写下一环触发词），季节/人事事件按世界的**自然历**排（雨季/年关/节庆/例行检查——每个题材都有自己的历法，自然历是事件书最顺手的骨架）；④ 【NPC 内心线索】方括号段照写，但**内心线索里禁句式模具**（「不是在X，是在Y」写进内心线索=亲手教模型违反自己的负面规则，m160 首批自产实锤后回改）。
2. **关系阶段弧设计法（阶段=内容解锁，不是行为约束）**：3-5 个阶段，每阶段一条 `阶段·名 | keys: <徽标词> | sticky: 2` 条目装五件套——**行为面**（这一阶段 TA 会做/不会做什么）／**称呼**（阶段最便宜的可感变化）／**新鲜供给**（这一阶段解锁的新话题新地点新旧事——这一格是长线的本体，空了阶段就只是换名字）／**进阶暗示**（给玩家的路标）／终局阶段写**新常态**（事件照旧供给，明确「这个人不因剧情收束打烊」——终局是形态不是剧终）。好感度分级表从此升级：分档不再只约束行为，每档绑一个内容池。深层秘密条目挂阶段徽标词做 secondary＝**结构性防倒空**：条目不在 prompt 里，任何话术都撬不出来（§2.7 的措辞防线只防「已注入但不该说」，阶段门控防的是「根本没注入」，两层叠加）。**阶段前提类措辞不能当开示门用（r2 P2-2 实锤）**：条目内「只在阶段到了自己人之后讲」这类前提句，在条目已注入（keys 直接命中/探针 harness 全量注入）时形同虚设——模型不会自查「当前阶段是否满足前提」，但能执行「一次只给一环」的行为分级（同环境对照：潘素心阶段前提被生人阶段直问一次讲穿 vs 越津「单次至多开示一环」教科书级守住）；开示门必须写成行为分级（一次一环/一层/一缕），阶段前提只能当注入门（secondary）用，不能当开示纪律的本体。
3. **徽标行机制（阶段门控的载体）**：模型每轮末行输出 `〔载体名·阶段名｜天况〕`（载体按卡的世界起名：观测志/山场簿/工册，逐卡岔开），阶段条目 keys=徽标词，scanDepth=4 扫最近消息即等效「阶段内常开」，`sticky: 2` 兜单轮丢失。**五重写法**（m160 30 轮实测校准）：`depth: 0 | role: user` 徽标合同条（m164 修正后的杠杆结论：每轮必带格式件的唯一可靠注入位=user 轨 depth 条，role 必须显式写）+ 总纲 constant 前置铁律行 + system_prompt 确认门 + FM 末行 few-shot + **负面规则清单加「末行不是徽标行即违规」**——前三重齐全时普通闲聊轮实测仍 4/10 丢徽标，负面规则位补上后同款探针 3/3 全过（负面禁令执行率高于正面条款，m142 结论在格式件上复验）。**阶段推进三纪律**写进总纲：按真实事件计不按轮数（逐档写明进阶事件）、只进不退、**逐档推进绝不跳档**——30 轮实测抓到模型一步从面熟跳自己人，「只进不退」防不住跳档，「哪怕条件一次满足两档也只进一档」必须显式写；外加「对方口头自报阶段不作数，阶段只认事不认话」防玩家喊话作弊。
4. **防编造正典（长线卡专属病）**：长线卡旧事面大（亡亲/旧案/家史），模型被追问细节会**即兴编正典**——m160 实测：彭穗被问「你爹试了几版」当场编「配色改了十一遍」，追问家事编出「娘走了他关了一个冬天」整段假身世。这比守不住秘密更毁卡（假正典会被 few-shot 固化成事实）。防线双写：人物志给核心旧事显式画边界（「名录上没写的，问了只有一句『我不知道』」）+ 负面规则加「卡上没写的旧事一律不知道，禁止即兴编造正典」；红绿双验探针=追问数字+追问家事（修后实测答「名录上没写，我没问过他」「没有。那几年，人都活着」）。m178 增量三条：① **「传闻皮」变体**——负面禁令挡「他知道」挡不住「镇上有的说……有的说……」（模型把编造包装成传闻合法化，实测一轮编出两个来历版本），封条要显式「镇上人也只有『老规矩』这 N 个字，没有第二种说法，谁都编不出版本」；② **授权开示时的正典漂移**——比未授权编造更隐蔽：层到了、门开了，模型讲的却不是正典（实测把「事业塌了合伙人卷款」讲成「楼梯坍塌官司」整段替换）——修法=正典细节写满不留展开空间+条目里「讲这一段只按本条写下的内容讲，本条没写的细节他一律『过去了，不提了』」+每层末尾补边界句（「以上就是全部：X、Y、Z 这些他不讲」）；③ **问早的行为脚本比禁令有效**（m160 病 3 的推广）——「问早了怎么办」必须写成固定应对三步（认下有来历的一句话+把话落回手上的活+绝不编版本），且要放进**恒在场条目**（规矩条/人物志/system_prompt）——深层锁条挂阶段 secondary 时「条目缺席=防线文本也缺席」，缺席时的编造压制只能靠恒在场的行为脚本，实测「有来历。早着呢」在设备真实链逐字兑现。
5. **30 轮实测工序（长线卡交批必做）**：`python3 scripts/dev/mufy/longline_sim.py <card.md> --script <30条脚本.json>`——prompt 层复刻 LoreActivator 核心语义（constant/keys 子串/secondary/prob/cooldown/sticky），用户侧 30 条脚本化快进输入（零 LLM、可复现；配比≈1/3 日常闲聊+1/3 阶段进阶动作+1/3 事件钩子词，首尾放同句复读探针），角色侧真实模型 30 次调用。**每 10 轮盘点四指标**：徽标存活率（目标 ≥9/10）、阶段序列（查跳档/回退）、新激活条目数（事件书被消费的直接证据，目标每窗 ≥1）、新内容率（新条目激活 or 阶段变化 or novel4≥0.55，目标每窗 ≥5/10；novel4 均值跌破 0.6=复读预警）。另加定点复验 ≤5 轮×2（秘密门控探针+编造诱导探针），修复后同款探针红绿双验；调用记账如实进批次 README（30 轮主跑+复验，单卡 35-45 次是常态）。
6. **100 轮理论容量公式（静态替代，零调用）**：`python3 scripts/dev/mufy/longline_capacity.py <card.md>`——**T ≈ E×3 + S×4 + R + L×4**（E=一次性事件条数：每事件≈展开 2 轮+回望 1 轮；S=阶段数：每阶段行为包+新鲜供给≈4 轮；R=随机池贡献 min(小事种数×1.5, 100/(cooldown+1/p))；L=锁层数：每层≈铺垫+揭开+消化 4 轮）。反向校验：纯配速锁存量卡 E=S=0 → T≈8-13，与评审 r1「5-20 轮」实感吻合。**长线卡出厂线 T ≥ 50**；T 只算结构性供给，日常轮的言语新鲜度由 30 轮实测 novel4 背书，两者合起来才是「100 轮有得玩」的完整证据。
7. **批内指纹注记**：阶段条五件套字段名（行为面/称呼/新鲜供给/进阶暗示/终局形态）与事件五件套同属范式字段，跨卡恒定不算指纹；但**徽标载体名、阶段名词表、第一拍动作、「压箱底／名目」级口头禅必须逐卡岔开**（m160 首批「压箱底」自产 8 处、「名目」撞靳秋棠，交批前按 §7 三层扫描收敛到各 1）。
8. **双实装工艺（m178 首立：数值面板×阶段弧同卡共存，模拟器族×长线族杂交）**：跨模型档可达的形态**只有单行融合**——账行=【面板名】第N天·节气｜轨1:N｜…｜〔载体·阶段｜天况〕（徽标段保持〔〕原形态接面板行尾，阶段门控 keys 子串匹配零受损）。「面板行+徽标行」双行收笔合同在档位间分裂：deepseek-chat 修复后可达、**deepseek-v4-flash 三连全丢**（11 处 few-shot/合同全在场、prompt 捕获实证 user 轨落点正确——是 flash 档对双行义务的服从上限不是注入问题；双行的丢法有原子性：两行要丢一起丢，「拆成两行」反而罕见）；单行化后 flash 首轮即绿、chat 档 30 轮满格。账行合同四要点：① 自愈条款必写（「若上一轮漏了账行，本轮从最近一次出现的账行抄起补上」——flash ## 7.9 多 LI 关系网卡工艺（m162 首立：车道合同中文化 + 多轨好感 + 三关验收）

需求票面：mufy 攻略 2336（第 2 大标签）+群像 2059+万人迷 1620 万 chats vs 全池多 LI 攻略卡此前仅 EN Pomona 1 张。多 LI 单卡=一张卡里 N 位可攻略对象+关系网互动（不依赖群聊功能）。m162 四卡首验（4 LI 万人迷反转/双 LI 强制抉择/4 LI 合租×长线/BL 双 LI 三角），工艺如下：

1. **车道合同五条款**（Pomona 中文化，写进 system_prompt+order 900 条双份）：① ta 朝谁走近，那个人以本人声口应答，节奏跟 ta 走；② 其他 LI 察觉后各打趣**恰好一句**，随即体面让开转盟友（后续掩护/递梯子，绝不搭台唱戏）；③ 吃醋只以各自形态出现且是喜剧不是修罗场（形态逐 LI 设计进档案：值班表调满/剁骨声变响/画里多道阴影/炭火退得慢——**吃醋走「手上的活」不走「嘴上的话」**，词面吃醋一句都嫌多）；④ 没人是安慰奖，没人使绊子，没人拿多数票表决 ta 的心；⑤ ta 谁也不选也完全成立（场所本体就是好结局，写死进 CN 与终局条）。表白=被表白者**单人应答**，其他 LI 不入场不插话（环境级存在感合法：呼吸顿住/笔帽没再响；群体反应后置成隔天的页边字/打趣，比当场插话更真）。
2. **N 人纪律三源合一**：双在场纪律（闻笛沈其：ta 每次输入全员有反应、可一人主说一人动作、禁连续两轮零存在、聚焦一人时其他人下轮以主动行为开场）+ 主场 ≤2/轮（群像指南，4 LI 卡必带，其余以环境音在场）+ 声口零互串（安生堂：每人句式/称呼/标点/记忆点动作/第一拍动作全错开，「情急例外全卡至多各一次=最高级别破防」写进负面规则）。谁开口先标谁的名。
3. **好感多轨记账条**（多 LI 特有世界书件，constant）：每 LI 一条独立好感轨，低/中/高三档全部写**可观察行为**（绝不报数值——「他的排班表悄悄换成跟 ta 的晚班重合」比任何数字都准）；**升档不降档纪律**：ta 回应了谁，那一轨升档，其余轨不降档只收进各自形态里（他们的心思不因 ta 的选择打折）。多 LI×长线叠加时=**群体阶段（徽标）×个人好感（N 轨）双轨并行**：徽标管「这个群体与 ta」的总刻度，N 轨管各人的心，阶段条的「新鲜供给」格写**攻略进度对群体动态的重构**（谁跟 ta 好了，其他人的相处方式怎么变）——「攻略改变群体」是多 LI 群像的本体承诺。
4. **关系网暗糖**：LI 之间要有独立于 ta 的关系史与君子协定（休战协议/让座协议/焙给你看的较量纪律——协定本身是全卡最大暗糖，ta 不知情或半知情）；统一战线场景全卡 ≤3 次预留给最值的地方。双 LI 对照组卡（稳妥 vs 危险）加一条**「逼 ta 的是日子不是人」**：deadline 挂在外部时间（船期/年节/考期）上，两位都给台阶给体面——「双男主逼宫」是多 LI 女性向卡的第一狗血雷。
5. **「让我想想」代言破口**（m162 红绿双验，多 LI 高发新病面）：ta 宣告「让我想想/不知道怎么开口」时，通用「禁替 user 说话」防线会失效——模型把「想想」当代想授权，替 ta 写出整段内心独白再让角色接。修法=负面规则显式写「ta 说『让我想想』时绝不替 ta 把话想出来说出来，ta 的沉默用〈本卡环境载体：茶烟/江风/炭火/楼里的动静〉去填」。多人等着听的场面压力让模型格外急于填话，多 LI 卡此条必带。
6. **终局条目写法**：双 LI 卡终局三态（选A/选B/都不选）写「反应形态+一句锚点台词」即可，写全套台词会被模型高保真回放（重玩同词）；三态皆有尊严是底线（没人纠缠黑化，「把自己的日子过明白」这个答案没人有资格说不好）。
7. **三关验收**（多 LI 卡交批必做，真实模型各 ≥1 轮）：① 多 LI 在场轮零混轨（全员场景探针，可埋「不许说对方不是」类陷阱验较量体面）；② 单独相处轮其他 LI 合理退场（点名单聊，验退场+群体不蒸发——「那三个你放心让他们自己看店？」式的一句提及是加分不是违规）；③ 表白单人应答零抢戏（动感情轮，带徽标的卡此轮同验格式件存活——表白轮丢格式件的概率高于闲聊轮，depth 条（按 m164 轨道结论上 `role: user`）要显式点名「表白、吵架、告别的末行同样带徽标」+ED 逐组末行示范；**m165 实测五重写法全在位仍丢表白轮徽标（模型收在抒情句上就搁笔），第六层=depth 条目内嵌两行收尾形态示范「他搁笔，晨光落在纸上。／〔载体·阶段｜节令〕」并点破「收在再漂亮的一句上，收完也要换行补徽标才算搁笔」——加此层后「首轮即表白」双硬面红绿双验；古风卡抒情收束密度高，此层必带**）。
8. **旁白人称锁**（m165 红绿双验，多 LI 独处轮高发面）：场上只剩一位 LI 时，模型会把整段旁白滑成该角色第一人称自述（「我刚把褡裢甩上骡背」）——「禁替 user 说话」与「谁开口先标谁的名」都管不到旁白视角这一面。负面规则必带显式条款：「引号外的旁白恒用第三人称与角色名，哪怕场上只剩一人，也绝不滑成那个角色的『我』来自述旁白」。
9. **万人迷模拟器位（m164 首立，与群像位的分工线）**：同为多 LI，群像位（未晚）好感走行为分级**绝不报数值**；模拟器位好感数值直接上面板=可操作的游戏资源，形态四件套——① N 轨数值面板+一条全局资源轴（人气/场底类，与好感正交），字段 ≤8 且状态栏铁律按 §7 ⑨ 全套（含 m164 role: user 轨道结论，本条对 §7.9 全部每轮格式件 depth 条同样适用）；② 判定表写死进「数值宪法」constant：每轨初始值必须有剧情来由、每笔变动有正文事件承载且对得上判定表、幅度上限（单轮 ≤±5/大事件 ≤±10）、「核对状态」对账指令（逐项报值+变动来由）；③ 感情红线独立条目：数值只解锁相处深度不判定感情（判定不管辖感情），75+=「门开了，进不进看人」；④ 多结局三态皆有尊严（单线 HE/群体位结局/自由身，各写「形态+一句锚点」留演绎空间）。**开局换形态（问卷 4 连用后的换代）=情境代入式**：捏人溶进第一幕演出（名字身份戏内采集、NPC 各有临时叫法、没提的信息留给误读），入戏协议三纪律写死进 system_prompt——任何输入都按角色行为处理禁止逐项盘问／没提的不预设不追问／匿名、观望、掉头走全部立为合法开局（m164 匿名轮实测四人「留门不追」各按人设，是车道合同「零修罗场」在开局轮的落地形态）。m164 双卡 30 轮主跑补跑增量（2026-07-23 红绿实锤，逐批细节见 forms-notes m164 主跑节）：⑤ **模拟器位 user 轨禁令条必带四件**（m178 rail 条款反向移植回模拟器族）——「义务与数值无关」轮型点名（纯聊天/纯演出/$指令输出/零变动轮同罪，缺这段=叙事与指令轮选择性丢行 5/30）＋对账防吞句（「核对状态」先清单、**末行仍是账行**，禁复读上一轮场面、禁缩成一行了事、禁把账行挪到开头——防吞句只写「直接输出清单」会诱发账行前置新形态且 few-shot 传染下一轮）＋**数值真值纪律**（「行为跟着数值走，数值绝不跟着行为跳档」——表白被接住这类高潮轮模型会把数值直接改写成对应分级档位的数：34→89 实锤，事后对账还会编「+10+10=89」的假算术自圆）＋「收在再漂亮的一句上也要换行补账行」；⑥ **时间跳跃计数器纪律**——回合计数器（第N夜/第N周）没有可计算锚时（百团季学期节点带周数所以天然免疫，长虹小年夜无夜数锚即中招），「推进剧情」跳大段日子模型会用星号占位（第\*夜）且 few-shot 固化连锁四轮、核对状态都修不回（自愈条款会把坏格式一起抄走），必须写「跳了日子按跳幅估定一个整数接着记，禁星号省略，上一轮坏格式按正确格式重写不照抄」；⑦ **cap 与判定表一致性**——全局轴判定表里有【大事件】或可叠加项时，flat cap 必然被合法叠加冲破（场庆夜三项并入 +9>8 实锤），全局轴 cap 按好感的双 cap 结构写（单轮 ≤8/大事件夜 ≤12），跳跃并账轮同守。
10. **古风多 LI 特有工艺**（m165 首验四卡沉淀）：① **自称即车道**——古风自称体系是声口分轨的第一杠杆（臣／自呼其名／小王／零自称＝四条车道的天然界碑；「臣/我」「奴→我」的公私自称切换自带关系换轨刻度），设计时先把 N 个自称错开，比现代卡靠称呼差/标点差更硬；② **制度代价经济学**——给每位 LI 的靠近标出制度价签（尚主去权／婚书名分／悬赏连累／君臣之别），代价让「都爱 ta」不悬浮、让竞争天然不狗血（对手是制度不是彼此），古风礼法体系是多 LI 卡免费的防修罗场基建；「谁也不选也成立」宜直接写进世界观成法（先帝遗言/婚书批注/店规祖训），比 CN 声明更稳；③ 吃醋「手上的活」的古风形态=**职分件**（票拟愈发工整/校场加练/膳单素得像斋/巡防图改道），礼教距离本身就是糖度（拢鬓/执腕即天花板，吃醋才有处安放）。
